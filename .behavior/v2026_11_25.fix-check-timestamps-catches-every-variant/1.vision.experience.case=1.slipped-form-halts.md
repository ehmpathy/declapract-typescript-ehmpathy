# 1.vision.experience.case=1 — a slipped form halts

inventory rows 1–12. feel: sharp. care: critipath.
notation per `1.vision.experience.dimensions.md`; no real clock appears here.

## .narrative

a clone writes a session yield. it pastes a log line that carries `hhmmZ` and a title line that reads
`YYYY-MM-DD hhmm`. today the hook reads neither as a clock, the commit lands, and the hour the human
sat at the desk ships to every clone of the repo.

after this work the same `git commit` halts. the clone sees the same `✋ ConstraintError` header it
already knows, the file, the line, and the line content. it masks the clock to `[time]`, restages,
and the commit lands. no new message, no new flag, no new habit: only the set of forms grows.

```
  when [t1] the dev masks the clock to `[time]` and restages
    then it exits 0
```
