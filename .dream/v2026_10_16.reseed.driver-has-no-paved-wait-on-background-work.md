# 🌙 dream: a driver has no paved way to wait on its own background work

kind: reseed · owner: ehmpathy/rhachet-roles-ehmpathy (mechanic, check-permissions) · caught v2026_10_16

## .the cue that fired

a 28-min integration suite (`git.repo.test`, auto-backgrounded past 600s) held the last proof of a
self review. the stop hook re-emits the stone each turn; `sleep N` is not paved
(`rhx permissions.get --for 'sleep 300'` → "no paved path fits this part"), and a repo-local skill
cannot be made executable (`chmod` is not paved either).

## .the gap, precisely

- no allowlisted command blocks for a bounded time
- so a driver that waits on a background task can only end its turn and be re-prompted, turn after turn

## .the shape of the fix

a mechanic skill `rhx await.output --file <path> [--pattern <regex>] [--timeout 540]` that polls an
output file every 15s, prints its tail on match, exits 2 on timeout. read-only. pave it in the
mechanic role so `chmod` is the package's job, not the driver's.

## .why it is not done in this round

the skill belongs to another repo (S5: no work in other repos); a draft here could not be made
executable without an unpaved `chmod`.
