## convergence — one file, two declarers

the repo-root `.gitignore` has two declarers (`git` + `rhachet`). both emit
`sorted(file ∪ ownSet) ++ orderedTail` via the shared `defineExpectedGitignoreContents`, so
the new sortable line unions in and the two converge byte-identical in either order. rhachet
declares ONLY its own `ignoresSortable`; the algorithm + ordered tail are imported, so the
drift that would break convergence cannot be written.
