## what folds in a pr, and how to un-fold a path

a repo that adopts these practices gets `linguist-generated` lines, so github renders robocode
collapsed in a pr. each stays one click away.

| folds | declared by |
|-------|-------------|
| `*.test.ts`, `*.test.tsx` | `tests-any` |
| `src/access/daos/**/.generated/**`, `provision/schema/**/.generated/**` | `persist-with-rds` |
| `src/access/daos/**/.generated/**` | `persist-with-dynamodb` |
| `.route/**`, `.behavior/**`, except `*.yield.*` and `.radio/**` | `rhachet` |

snapshots (`*.snap`) stay open: no line names them. the daos and the schemas stay open too: they
are the internal contracts. only the `.generated/` dirs within them fold.

to un-fold a path, add a line at the bottom of `.gitattributes`, below every `# [<declarer>]`
section and apart from them by a blank line:

```
src/access/daos/.generated/** -linguist-generated
```

the repo's own lines always sit last, and git takes the last line that matches, so this line wins.

- a dir-level line un-folds every file under it, test files included, since it outranks the
  `tests-any` line too
- one file un-folds with a line of its own:
  `src/access/daos/.generated/queryFunctions.ts -linguist-generated`
- leave your own lines untagged. a `# [<word>]` header marks a managed block: it floats above the
  repo-own lines, and one that names a declarer is rewritten by that declarer's fix

a folded file may also drop out of github code search, which skips generated files.

## `.agent/.cache/` is declared here and by the rhachet practice

deliberate, and neither is redundant. rhachet owns the dir in the causal sense — it creates it —
which is a different claim from which practices declare the ignore for it.

this line stays because `app-react-native-expo` (`src/useCases.yml`) takes `git` **without**
`rhachet`, so for those repos it is the only explicit source of the ignore. `.cache/` happens to
cover `.agent/.cache/` at any depth, but that coverage is implicit — narrow `.cache/` and it is
gone. the same caution sits in `.gitignore.declapract.ts`, at the point of edit.

## this repo consumes this practice

`declapract.use.yml` sets `useCase: npm-package`, which extends `typescript-project`, which
carries `git`. so `[case3]` in `src/practices/git/.declapract.integration.test.ts` checks this
repo's own `.gitignore` against the declaration — add a line to `ignoresSortable` and it goes red
until the practice is applied here too.
