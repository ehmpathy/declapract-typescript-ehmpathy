## the defect — provision:testdb's inner schema calls carried no ACCESS, so a fresh repo could not derive access

`persist-with-rds/best-practice/package.json`'s `provision:testdb` chains three inner
`provision:schema:*` calls. each invokes sql-schema-control → getConfig() →
getEnvironment.static(). with no ACCESS in a local shell (no aws account alias / NODE_ENV that
fits), every access parser fails and it throws `could not derive access`. so a freshly-stamped repo
could not provision its local testdb without a hand-edit.

the tell it was a template bug, not a preference: the cicd live-db path
(`.sql-schema-control.yml`) already sets `ACCESS=${{ inputs.stage }}` on the identical schema
calls. the local `provision:testdb` chain was left without the parallel — an asymmetry, not intent.

## the fix — ACCESS=test on every inner schema call (a constant, not the cicd interpolation)

`provision:testdb` now prefixes each of the three inner schema calls with `ACCESS=test`. the local
testdb always provisions the `test` tier, so it is a constant here — NOT the cicd
`${{ inputs.stage }}` interpolation. package.json is a `CONTAINS` check, so the shipped bytes are
checked against every consumer: a consumer still on the bare chain is flagged, with the target
shown.

## the clamp — provision-testdb-access.declapract.test.ts (practice root, 2 tests)

reads the shipped best-practice package.json and asserts:
- each inner schema call carries `ACCESS=test` (contains the `ACCESS=test npm run
  provision:schema:plan` / `:apply` forms), and
- NO bare `&& npm run provision:schema:` survives (a bare call is the #563 defect).

teeth confirmed: drop one `ACCESS=test` from the template and both assertions go RED (a bare `&&
npm run provision:schema:apply` reappears). restored → 2 GREEN. the clamp sits at the practice ROOT,
so declapract never emits it (per the #583 relocation convention).

## the north-star flag (per vision §3)

⚠️ the parallel cicd live-db path writes `ACCESS=${{ inputs.stage }}` — it uses the *stage* value
where *access* is meant. correct today only because they happen to agree there, but it is exactly
the divergence the north-star `stage`-elimination guard must forbid. flagged for the collapse, NOT
copied here: this local path uses the constant `test`, which is unambiguous and correct on the
access axis regardless of the stage collapse.
