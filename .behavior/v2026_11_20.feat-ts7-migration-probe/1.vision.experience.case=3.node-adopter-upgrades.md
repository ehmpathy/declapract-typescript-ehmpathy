# case=3 · node adopter takes the practice on next upgrade

feel: happy · care: critipath

## .narrative

kai maintains `svc-wavereports`, a `lambda-service` usecase. a routine `declapract upgrade` lands. the plan shows a small diff. `package.json` moves `typescript` to `7.0.2`. `tsconfig.json` gains `"types": ["node", "jest"]` and `./`-prefixed paths from the best-practice. it loses `baseUrl` and `importsNotUsedAsValues` to the bad-practice `tsconfig-options-removed-in-ts7`. kai's tsconfig matched the old practice exactly, yet it still needs the strip: a `CONTAINS` fix adds keys and never deletes one. the best-practice fix re-serializes the file as plain json, so kai's tsconfig comments do not survive the apply; kai's own `"types": ["vitest/globals"]` does, after the `node`, `jest` lead. kai runs `pnpm install`, then `npm run test:types`. it finishes before kai can switch windows. `npm run build` emits `dist/` with `@src/*` imports rewritten by `tsc-alias`, same as before. ci goes green. no source file changed. kai's tests still run through `@swc/jest`, which never touched the compiler.

the aha: the slowest gate in kai's pre-push loop is now one of the fastest, and the upgrade cost was a reviewed config diff.

## .timeline

```
given('a lambda-service repo with a conformant tsconfig on typescript 5.4.5')
  when('[t0] the maintainer runs `declapract plan`')
    then('package.json: typescript floor → 7.0.2')
    then('best-practice tsconfig.json: paths prefixed `./`; types declared')
    then('bad-practice tsconfig-options-removed-in-ts7: flagged, though the tsconfig matched the old practice')
  when('[t1] the maintainer runs `declapract apply` + `pnpm install`')
    then('baseUrl + importsNotUsedAsValues are gone; the adopter types entries stay after node, jest')
    then('a re-run of `declapract plan` shows no fix left (converged)')
  when('[t2] the maintainer runs `npm run test:types`')
    then('it exits 0 with no new errors')
  when('[t3] the maintainer runs `npm run build`')
    then('dist/ emits; `@src/*` imports are rewritten to relative paths by tsc-alias')
  when('[t4] the maintainer runs `npm run test:types` again in the daily loop')
    then('wall time sits near the probe ratio, not the 5.4.5 baseline')
```
