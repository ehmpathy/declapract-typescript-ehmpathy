# case=2: a green bot pr waits for a review

feel: happy · care: critipath. the incident path (sdk-aws-lambda#79), replayed under the gate.

## .narrative

seaturtle[bot] opens a fix pr and runs `rhx git.release --apply`, which turns on automerge. all
nine checks go green. before, the pr merged at once, unreviewed (#79: authored and merged by
`ehm-seaturtle`, zero reviews). now the pr shows "review required" and automerge holds. a human
reads the diff and approves. automerge merges.

## .bdd sketch

```
given main requires one approval
  given a pr by seaturtle[bot], automerge on
    when [t0] every required check passes
      then the pr does not merge
      then reviewDecision = REVIEW_REQUIRED
      then today: `git.release --watch` polls `await automerge` to a 15m `⏰ timeout`; it never
           names the review (same gap as case=3, same upstream dream)
    when [t1] a human with write approves
      then reviewDecision = APPROVED
    when [t2] automerge fires
      then the pr merges into main
```
