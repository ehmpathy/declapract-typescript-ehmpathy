# case=5 — the sender sees its task land (e7)

## .narrative
a clone in svc-notifications filed #806 and moved on. weeks later, its next upgrade is due. it runs `rhx radio.task.pull --via gh.issues --from ehmpathy/declapract-typescript-ehmpathy --exid 806` and reads `DELIVERED`, with a comment that names the pr and the version. it can drop any local workaround it was asked to keep.

a clone in bhuild filed #788. the radio reads `CLAIMED`: nine items shipped, item 2 (a timestamp exemption for `.eco/*`) declined, with one line: the hook takes no exemption by rule; the store's writer must stop the clock; a reseed went to bhuild. it knows where its next move is.

a clone in app-storefronts-web filed #801. the radio still reads `QUEUED`, and the issue carries one comment: one release out, since a rename of a required check strands every adopter's first upgrade pr until the stable gate in this release reaches their protection.

## .timeline
```
given('a clone that filed #806, weeks before its next upgrade')
  when('[t0] execution here begins on #806')
    then('its radio status moves QUEUED -> CLAIMED')
  when('[t1] the release pr merges and the version is cut')
    then('#806 reads DELIVERED, with a comment that names the pr and the version (or 0.50.0, where it landed there)')
  when('[t2] the clone pulls its task before it upgrades')
    then('the status alone tells it its fix shipped; it drops its local workaround')
given('a clone that filed #788, a task partly fixed')
  when('[t0] the clone pulls its task after the release')
    then('it reads CLAIMED, with a comment: what shipped, and the reason the rest stays (the reseed named)')
given('a clone that filed #801, a task left open')
  when('[t0] the clone pulls its task after the release')
    then('it reads QUEUED, with one comment: the reason, and what unblocks it')
```
