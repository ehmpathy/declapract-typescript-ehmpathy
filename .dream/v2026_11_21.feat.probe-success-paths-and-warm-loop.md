kind: feat · owner: declapract-typescript-ehmpathy · caught 2026-11-21

## .the cue that fired
peer reviews of the ts7 pr found two probe gaps. r010 i005: the dev's daily loop, a warm incremental re-check, is unmeasured. the template sets `incremental: true`, and the probe forces `--incremental false`. r011 i006: emit trees pile up in `.temp/`, and the `7.0.2` and `7.0.2:single` rungs share one dir.

## .the gap, precisely
- catalog row 9b itemizes the warm loop as unmeasured; no ratio is claimed for it
- `typescript.probe.sh` names each emit tree by the version alone, and keeps every tree after its report

## .the shape of the fix
- key each emit tree in `.temp/` by the full rung, and clear the tree after its report is read
- add `--warm`: one `tsc --incremental` run writes buildinfo, then N timed re-checks with no source edit, read the same way (median, min–max). report it as its own table, never mixed with cold runs. snap it as the acceptance suite snaps the cold report

## .why it is not done in this round
the pr's measured claim is cold only, which is the ci shape, and the yield says so. both items extend a dev tool; they change no practice an adopter receives.
