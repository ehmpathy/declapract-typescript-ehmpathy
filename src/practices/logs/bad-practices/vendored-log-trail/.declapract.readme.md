a vendored copy of visualogic's `withLogTrail`.

the copy drifted from the library: it logs no error on a throw, so each op it wraps is silent when
it fails, and it takes a variadic arg list where `withLogTrail` takes `(input, context)`. the move
is a shape change at each op and each caller, so the fix stamps a `// @declapract:review:` line
above the fork that names the move, and rewrites no code.
