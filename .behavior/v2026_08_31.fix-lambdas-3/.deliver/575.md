# deliver: #575 — the pnpm practice deletes the inert v11 allowBuilds block it never wanted

## what shipped

a new `pnpm` bad-practice — `inert-build-allowlist` — that **detects a `pnpm-workspace.yaml` that
carries an `allowBuilds:` block and removes it**:

- **`pnpm-workspace.yaml.declapract.ts`** — `check` returns (detected) when the file holds an
  `allowBuilds:` key, throws (skip) otherwise; `fix` strips the block and, when the block was the
  file's sole content, deletes the whole file (`{ contents: null }`).
- the block is stripped by line, so a `pnpm-workspace.yaml` that holds `allowBuilds:` **beside**
  a real key (`packages:`) keeps that key and loses only the inert block.

## why this is the right fix — detect + delete, not fail-loud and not boolean-fill

`allowBuilds:` is pnpm **v11** syntax (a package→boolean map, in `pnpm-workspace.yaml`). the pnpm
practice pins **v10** (`pnpm@10.33.4`), where the build allowlist is `pnpm.onlyBuiltDependencies`
(an **array**, in `package.json`). so an `allowBuilds:` block under the v10 pin does **zero work** —
yet it READS like a live allowlist. that is the exact trap #575 / `ehmpathy/rhachet#475` burned an
hour on: config that looks handled and does no work.

two reasons the fix is DELETE, not a stub or a fill:

1. **there is no allowlist to converge to.** rhachet retired the manual allowlist step "by
   subtraction" — it deleted its own `onlyBuiltDependencies` node-pty entry and the suite stayed
   green, because the prebuild ships in the upstream tarball. so declapract emits no allowlist.
2. **a real allowlist is repo-specific** (the v10 `pnpm.onlyBuiltDependencies` array the repo adds
   itself). a template cannot synthesize it. an inert block does no work, so its removal cannot
   regress a build — the safe, idempotent move is to remove it.

## idempotency

after the fix the `allowBuilds:` key is gone, so `check` no longer detects it and a re-apply is a
clean no-op. when the file was sole-content it is deleted, and a re-apply on the absent file is a
no-op too (check throws on `null`).

## the clamp — teeth dogfooded

- **unit** — `pnpm-workspace.yaml.declapract.test.ts`, 8/8: detect · delete-when-sole · strip-keep
  when a real key coexists · not-detected when no `allowBuilds:` · not-detected on `null` ·
  idempotency for both the delete and the strip-keep paths.
- **integration** — `[case4]` in `src/practices/pnpm/.declapract.integration.test.ts`: the real
  `executeApply` pipeline against a `genTempDir` clone whose `pnpm-workspace.yaml` holds ONLY the
  inert block → asserts the file is **deleted**, a before-snapshot of the removed block, and a
  fixed-point on re-apply (absent stays absent). 14/14 green.
- **teeth** — neutered the fix to a no-op → `[case4]` went RED (2 failed: the delete assertion and
  the fixed-point). restored → 14/14 green.
