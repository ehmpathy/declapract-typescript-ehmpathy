## the leak — practice-internal test files sat under best-practice/, so declapract copied them to consumers

declapract's emission classifier (`getProjectCheckDeclaration.js:28-34`) treats every file under a
`best-practice/` dir that is NOT `.declapract.`-prefixed as a TEMPLATE to copy into the consumer
repo. a `*.declapract.test.ts` (or `.declapract.integration.test.ts`, or a `__snapshots__/*.snap`)
is not a template — it `import`s `declapract` + `test-fns` and clones
`./src/practices/.../.test/assets/...` fixtures that exist ONLY in this library. copied to a
consumer, it materializes at the consumer root and fails jest load (ENOENT on the clone fixture, or
absent dev deps). traced live on the app-protools-native upgrade (#583).

## the fix — relocate every such test out of best-practice/ to the practice ROOT

the practice root is the declapract-safe home: declapract walks only `best-practice/` and
`bad-practices/*/` for emission, never the practice root (the same reason
`src/actionPins.declapract.integration.test.ts` and my own clamps already live outside
`best-practice/`). moved **~19 test files + ~11 snapshots** across **16 practices**, rewriting each
sibling declaration import `./X.declapract` → `./best-practice/X.declapract` (and, for the deeper
homes, the full sub-path). the declarations themselves stay under `best-practice/` — only the tests
moved.

practices touched: format, package-json-order, serverless, tests-node (×3), typescript-node,
tests-any, typescript-expo (×2), cicd-app-react-native-expo, git (×2), lint, node (×2), rhachet,
persist-with-rds, tests-service, cicd-common, cicd-service (×2).

edge cases handled:
- **cross-practice imports** (cicd-expo, rhachet import git/rhachet's `.gitignore.declapract`) lost
  one `../` — the test moved up a level, so `../../git/best-practice/` → `../git/best-practice/`.
- **`__dirname` template reads** (typescript-expo package.json + tsconfig integration tests, the
  persist-with-rds `.extensions.sql` test) gained the `best-practice/...` sub-path, since `__dirname`
  is now the practice root.
- **`process.cwd()`-relative clone/fixture strings** (node `.npmrc` + cicd-service `provision.yml`
  integration tests) needed NO change — they read from the repo root, not the test file.
- **the literal-`*` filename** (`tests-service/*.acceptance.test.ts.declapract.test.ts`) moved via
  `mvsafe --literal`.

## clamp

`src/practiceTestFileLocation.declapract.test.ts` (3 tests) — walks `src/practices/**` via
`getAllPathsUnderDir` (node `readdirSync`, which descends dot-dirs) and asserts NO
`*.declapract.test.ts`, `*.declapract.integration.test.ts`, or `__snapshots__/*` sits under any
`best-practice/`. teeth confirmed: RED (3 failed) before the relocation, GREEN (3 passed) after.

the clamp earned its keep mid-fix: it caught two more leaks my globs missed —
`cicd-common/.github/workflows/.test.yml.declapract.test.ts` and cicd-service's `provision.yml`
tests — because `.github/` is a dot-dir that glob `**` skips but `readdirSync` descends. it lives at
`src/` (never walked for emission), the same safe home as `actionPins`.
