# case=1: a fresh rds adopter upgrades and the cycle check is green

covers inventory #1 (adopter) and #19 (maintainer). `[t0]`–`[t2]` match the usecase walk in
`typecheckBestPracticeTemplates.declapract.integration.test.ts`. its `[t3]` proves no cycle through pg-pool, but the
walk's bare repo exits 1 on causes outside this wish (F5). the exit 0 and the red without the patch are proven by
`pg-pool-patch.declapract.integration.test.ts` `[case6]`, on an isolated pg + pg-pool tree.

## narrative

kai owns a lambda service on postgres. kai bumps declapract-typescript-ehmpathy and runs `npx declapract apply`.
the apply writes `patches/pg-pool.patch` and adds `"pg-pool": "patches/pg-pool.patch"` under
`pnpm.patchedDependencies`. kai runs `pnpm install`; pnpm patches pg-pool. `npm run test:lint:cycles` exits 0. kai
never learns pg-pool had a cycle.

the maintainer of this repo sees the same four steps run in ci, per usecase, on every pr. the `[t3]` step is the clamp:
with the patch removed from persist-with-rds, `lambda-service-with-rds` goes red.

## bdd sketch

```
given('[case1] a bare repo that adopts lambda-service-with-rds')
  when('[t0] declapract apply')
    then('package.json pnpm.patchedDependencies holds "pg-pool": "patches/pg-pool.patch"')
    then('patches/pg-pool.patch exists and drops the require(\'pg\') fallback')
  when('[t1] the deps are pinned to their floors, and declapract apply runs again')
    then('a plan flags no file for an automatic fix')
  when('[t2] pnpm install')
    then('the install exits 0')
  when('[t3] npm run test:lint:cycles')
    then('it reports no cycle through pg-pool')                       // walk [t3]
    then('on a tree whose only cycle source is pg, it exits 0')       // [case6] [t0]
    then('without the patch, it exits 1 and names pg <-> pg-pool')   // [case6] [t1], the clamp's teeth
```
