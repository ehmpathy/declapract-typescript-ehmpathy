# 1.vision.experience.dimensions

the experience space of the ts7 probe, factored into orthogonal axes. the product is walked in `1.vision.experience.case=_.md`; every inventory row is a coordinate in this product.

## .dimensions

| axis | values | why it varies the experience | why it is orthogonal to the rest |
|---|---|---|---|
| **A. actor** | `prober` (runs the rungs, decides the verdict) · `wisher` (reads the probe pr) · `adopter` (a repo maintainer who runs `declapract plan` / `apply`) · `dev` (runs `test:types` in a daily loop) · `ci` (runs `test:types` + `build` on push, unattended) | each meets a different face: a pr body, a diff, a wait, a gate | who walks is fixed before any repo state or outcome is known; every actor can meet every other coordinate |
| **B. probe verdict** | `holds` · `fails` | each yields a different pr, and only `holds` ships a practice change | decided by the probe on this repo, independent of any one adopter's runtime, tsconfig, seam, or install |
| **C. runtime half** | `node` (typescript-node) · `expo` (typescript-expo) | expo sdk 56–58 expects `typescript ~6.0.3`; node has no such cap | set by the adopter's usecase, chosen long before the probe and independent of how they edited their tsconfig |
| **D. adopter repo state** | `conformant` (matches today's practice, which itself carries `baseUrl: "."` + `importsNotUsedAsValues`) · `drifted` (hand-edited further: `baseUrl: "./src"`, `moduleResolution node`) · `extended` (adds its own to what the practice declares: a `types` entry such as `"vitest/globals"`, or src code that imports the compiler api from `typescript`) | conformant keys strip by rote; drifted ones may need a human; an extension must survive the apply, or be flagged when it cannot | a property of the adopter's file, set by past hand-edits, independent of runtime or of what typescript is installed today |
| **E. compiler seam** | `typecheck` (`tsc --noEmit`) · `build` (`tsc` emit + `tsc-alias`) | the build seam adds `tsc-alias`, which reads `paths` without the compiler | which command runs is chosen per invocation, whatever the repo state |
| **F. installed typescript** | `<7` (5.x or 6.x: a node adopter before upgrade, an expo repo on its sdk pin, the prober's 5.4.5 and 6.0.3 rungs) · `half` (practice applied, `pnpm install` not yet run: new tsconfig on `<7`) · `7.x` (after install) | each install meets the tsconfig differently: `<7` accepts the old shape (6.x warns, 5.x is silent), half runs the new shape on an old compiler, 7.x rejects removed options. 5.x and 6.x share a value because both accept every key the strip removes; the walk never needs them apart | moves on the adopter's own clock (`pnpm install`), not with the tsconfig file or the actor; a half state exists exactly because F and D change in separate steps |

outcome is not an axis. "silent pass" or "unrewritten `@src/*`" are results a coordinate produces. the inventory names them as forbidden outcomes of a coordinate, not as coordinates.

## .the walked product

`A × B × C × D × E × F` = 5 × 2 × 2 × 3 × 2 × 3 = 360 raw cells. they collapse by rule, each stated:

1. **`wisher` meets only B.** the pr body is the same whatever C–F a future adopter has → 2 cells.
2. **`prober` meets one fixed coordinate on this repo** (node · conformant · both seams), walks F across all rungs, and its walk decides B → 1 dense cell.
3. **B = `fails` reaches no adopter, dev, or ci**: no practice change ships → impossible for them.
4. **C = `expo` meets no compiler change**: the floor stays out of typescript-any (F2), so F never leaves `<7` for expo via this practice → 1 cell per actor; F = `7.x` under expo is forbidden.
5. **`dev` and `ci` collapse into `adopter` on D = `drifted`**: the first to run `declapract plan` meets the flagged bad-practice; dev and ci only meet the same plan output or the same ts7 error that the adopter's walk shows.
6. **`dev` and `ci` collapse on E = `typecheck` × D = `conformant`**: the same command and the same output; ci is dev, unattended.
7. **F = `<7` with B = `holds`** is the before-state of every adopter walk; it is a `given`, not its own experience.
8. **D = `drifted` collapses onto other cells once `declapract apply` runs**, by what is left in the tsconfig:
   - **drifted × build**: the apply (`baseUrl` folded into `paths`, `importsNotUsedAsValues` dropped, `moduleResolution` set to `node16` by the best-practice) leaves the build seam the same as a conformant repo's, so it collapses into the conformant build cell (case=7).
   - **drifted × half**: on `<7`, the folded tsconfig still compiles, the same as conformant × half (row 8). the edge arrives only when `pnpm install` lands 7.x, which is the drifted typecheck cell (case=4).

9. **D = `extended` meets only the adopter at typecheck × 7.x**, in two cells by what the repo adds:
   - **extended types**: the best-practice fix unions `types`, so the apply keeps the entry and every later seam matches the conformant one.
   - **extended api import**: the plan flags each such file `FIX_MANUAL`; dev and ci meet the same flag or the same TS2305/TS2339 error (rule 5).

the inventory lists every cell left after these rules, plus the forbidden ones.
