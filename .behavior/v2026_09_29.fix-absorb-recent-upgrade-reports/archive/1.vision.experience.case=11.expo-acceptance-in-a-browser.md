# case=11 — an expo app's acceptance tests run in a real browser

critipath · feel: happy, one sharp stop · cells: A=adopter × B2/B7 × C1/C3 × D1, A=system × B7 · issues: #603, #604, #609, #617

## .narrative

before: app-protools-native hand-copied a playwright setup. metro picked up the `.play.test.ts`
files and tried to bundle playwright into the app. its hand-written `metro.config.js` required
`metro-config`, which the upgrade's depcheck blocker then rejected. and the shared ci workflow ran
every acceptance tier with jest flags, so the playwright suite could not run in ci at all.

after: the expo practice ships the setup. `play.acceptance.config.ts` builds the web bundle, serves
it, and runs chromium desktop and mobile with visual snapshots. apply inserts one blockList line into
the repo's `metro.config.js` (or writes the file if it is absent), so metro never bundles a
`.play.test.ts`, and no `metro-config` require is needed; depcheck also ignores `metro-config` in expo
repos. jest unit runs skip `.play.test` files. `test:acceptance` runs playwright when the play config
exists, else jest; the ci workflow detects the same and installs chromium only when needed.

the sharp stop: a `metro.config.js` with no `module.exports` anchor is left as is and the check stays
red, with the line to add.

## .[tn] sketch

```
given('[case1] an expo app with a metro.config.js that ends in module.exports = config')
  when('[t0] declapract apply')
    then('play.acceptance.config.ts exists and @playwright/test is a devDependency')
    then('metro.config.js blocks .play.test files, with no metro-config require')
    then('jest.unit.config.ts excludes .play.test files')
  when('[t1] npm run test:acceptance:locally')
    then('playwright runs the example .play.test.ts against the served web build')
  when('[t2] declapract apply again')
    then('zero files change, and the blockList line appears once')

given('[case2] a metro.config.js with no module.exports anchor')
  when('[t0] declapract apply')
    then('the file is untouched, and plan keeps it red with the line to add')

given('[case3] the ci test workflow on the adopted repo')
  when('[t0] the acceptance job runs')
    then('the runner is detected as playwright, chromium is installed, and no jest flag is passed')

given('[case4] the ci test workflow on a node service')
  when('[t0] the acceptance job runs')
    then('the runner is detected as jest, and the job runs as before')
```
