# 🌙 dream: a hermetic test harness for repo-local skills

- kind: entool
- owner: declapract-typescript-ehmpathy
- caught 2026_11_15

## .the cue that fired

the execution reviewers of `feat-require-main-review` asked for tests of
`rhx github.main-review.census`. jest ignores `/.agent/`, so its play test had to live in `src/`
(`src/practices/provision-github/github.main-review.census.play.declapract.integration.test.ts`),
with a `gh` stub of its own.

## .the gap, precisely

the other repo-local skills (`declapract.walk`, `husky.lock.restamp`, `declapract.validate`,
`route.concerns.dispose`, …) ship with no automated proof. each that grows a test must borrow a
practice dir and roll its own stub.

## .the shape of the fix

- a jest carve-out that reaches `.agent/repo=.this/role=any/skills/*.integration.test.ts`, so a
  skill's test sits beside the skill
- one shared stub kit (`gh`, `npx declapract`) under a test-assets dir, lifted from the census
  test's `gh.stub.sh`
- move the census play test beside its skill once the carve-out lands

## .why it is not done in this round

a jest config change ripples into every test run and past a pr scoped to one practice field. the
census, the one skill this pr adds, is covered.
