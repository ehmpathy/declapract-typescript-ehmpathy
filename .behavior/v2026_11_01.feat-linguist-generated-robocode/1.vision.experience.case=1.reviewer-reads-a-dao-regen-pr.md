# case=1: reviewer reads a dao regen pr

cells: rv1 · rv4 · rv12 — happy · critipath

## .narrative

kai opens a pr on `svc-jobs` that adds one field to `Job`. the pr touches 41 files.

before: the files tab is a wall. `src/access/daos/daoJob/*.ts`, `.generated/queryFunctions.ts`, `provision/schema/sql/tables/job.sql`, five test files, two snapshots, and the one domain object that matters. kai scrolls past ~1,900 lines of regen to find the 6-line change in `Job.ts`.

after: github shows `Job.ts`, the two `.snap` files, the hand-written operation, and the daos and schema sql, open: the daos and the schemas are the internal contracts. every file under a `.generated/` dir and every `*.test.ts` sits collapsed under "some generated files are not rendered by default", each with its `+N −M` count and a "load diff" link. kai reads the domain change, eyeballs the snapshot diff for the new field, and clicks one test file open to confirm the new assertion. done.

the aha: the snapshot is the proof the tests ran the new field; the test source is the how. kai reads the proof first and opens the how on demand.
