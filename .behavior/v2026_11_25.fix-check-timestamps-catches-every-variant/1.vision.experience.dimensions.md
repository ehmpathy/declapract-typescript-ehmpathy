# 1.vision.experience.dimensions

notation: `hh` = hour, `mm` = minute, `ss` = second, `h` = a one-digit hour, `YYYY-MM-DD` = a date.
no real clock appears here; this file is itself scanned by the hook it describes.

| actor | moment | what varies | verdict |
|-------|--------|-------------|---------|
| committer — a dev (human or clone) in any consumer repo | `pre-commit` runs `.husky/check.timestamps.sh` on each staged blob | the text in the blob (D1–D5 below) | demoed (case=1, 2, 3) |
| upgrader — a consumer maintainer | `npx declapract apply --practice husky` lands the new hook and its re-stamped lock, then a later commit edits an older file | whether that older file already holds a newly-caught form | demoed (case=4) |

| bot — an automated job that stages a generated file and commits | `pre-commit`, as for the committer | whether its generator writes a clock | itemized (row 27): it halts like any commit; the fix is in the generator (mask the clock), never a skip — per `rule.forbid.timestamp-hook-exemptions` |

## .dimensions of a time-of-day form

| # | dimension | values |
|---|-----------|--------|
| D1 | separator between parts | colon `:` · dash `-` · none (basic) · `h`/`H` mark · dot `.` |
| D2 | precision | hour only · hh+mm · hh+mm+ss · +fraction |
| D3 | hour width | two digits `hh` · one digit `h` |
| D4 | anchor that marks it as a clock | lead `T` · a date before (year-, month-, or day-first, numeric or month name) · a named zone after (`Z`, `z`, `UTC`, `GMT`) · a numeric offset after (`+hh:mm`) · a meridiem after (am/pm) · none |
| D5 | left edge | start, space, or quote · a colon (line:col shape) · a digit or letter (inside a token) |

### .orthogonality

- D1 is how the parts are joined; D4 is what sits around them. any separator can carry any anchor,
  so no D1 value implies a D4 value. the full 5 × 6 product is walked below.
- D2 and D3 describe the digits, not their joins or surroundings. each combines with every D1 × D4
  cell; they change only *which digits* a form accepts, so they are walked as one rule each (below)
  rather than as 4 × 2 more copies of the table.
- D5 is the text outside the form. it can hold any value next to any form; it decides false
  positives only.
- **hidden-dimension check.** a first pass folded the numeric offset into "zone", and the `h` mark
  into "edge". both were latent axes: a numeric offset collides with page ranges where a named zone
  does not, and the `h` mark is a separator, not an edge. both are split out above. no row or
  column below is empty, so no further axis hides in the product.

## .the walked product: D1 × D4

| D1 \ D4 | lead `T` | date before | named zone | numeric offset | meridiem | none |
|---|---|---|---|---|---|---|
| colon | **halt** (extant) | **halt** (extant) | **halt**; with a colon left edge too (zoned form) | **halt** (extant) | **halt** | **halt** (extant; left edge spares line:col) |
| dash | **halt** (extant) | **halt** (`YYYY-MM-DD_hh-mm-ss`) | **halt** (`hh-mm-ssZ`) | pass — itemized: `nnnn-nnnn` ranges share it | **halt** (`h-mm pm`) | pass — itemized: `dd-mm-yy` dates share it |
| none (basic) | **halt** after a date (`YYYYMMDDThhmmss`); pass alone — itemized: `Tnnnn` ids | **halt** (`YYYY-MM-DD hhmm`, `YYYYMMDD hhmm`) | **halt** (`hhmmZ`, `hhmm UTC`) | pass — itemized: ranges | **halt** for a 12-hour `hhmm pm`; a 24-hour hour + pm is malformed — impossible | pass — itemized: years, ports, counts |
| `h`/`H` mark | impossible — iso never writes it | **halt** (`YYYY-MM-DD hhHmm`) | **halt** (`hhHmmZ`) | **halt** — the `h` mark anchors on its own, so any offset after is moot | **halt** (`hhHmm pm`) | **halt** between two-digit parts |
| dot | impossible — iso never writes it | **halt** (`YYYY-MM-DD hh.mm`) | **halt** (`hh.mmZ`) | pass — itemized: decimals with a sign | **halt** for a 12-hour `h.mm pm` | pass — itemized: decimals and versions |

### .D2 and D3, as rules

- **D2 precision.** hh+mm, hh+mm+ss, and a fraction after ss halt wherever the cell halts. hour
  only halts with a lead `T` after a date (`YYYY-MM-DDThh`) or with a meridiem (`hpm`); elsewhere an
  hour alone is a bare number — itemized pass.
- **D3 hour width.** a one-digit hour halts with a colon (`h:mm`, F1) and with a meridiem. with a
  dash, dot, `h` mark, or none and no meridiem, one digit is too loose a shape — itemized pass.

## .the bounds (D5)

- colon left edge: a colon or digit before the hour → pass (line:col `file.ts:hh:mm`, port maps),
  unless a named zone follows, which rules out the line:col sense
- token edges: a letter, digit, dot, or dash next to a basic or zoned form → pass (hashes, base64,
  ids, versions)
- a span: an iso duration (`PT…`) is stripped before the scan; extant rule
