this bundle defines the runtime-agnostic half of the typescript triad: the shared
typecheck that every runtime runs, regardless of how it builds or bundles.

namely:
- the `test:types` command — `tsc -p ./tsconfig.json --noEmit`
  - typechecks without a build, so it runs the same on node and expo
  - the runtime halves (`typescript-node`, `typescript-expo`) ship the tsconfig it points at
- the `typescript` dev dependency, pinned to a shared floor

why a runtime-agnostic half:
- the typecheck is identical across runtimes; only the build/bundle differs
- so the shared command + dep live here, and each runtime half declares only its own
  tsconfig + build (tsc-alias for node, metro/expo for expo)

see the runtime halves for the build-specific config:
- `typescript-node` — node16 tsconfig + `tsc` + `tsc-alias` post-compilation build
- `typescript-expo` — `expo/tsconfig.base` + `expo export`, bundled by metro (no tsc build)
