`getOneDatabaseConnection`. the old file reads a config key the practice removed, so it fails tsc.

this fix:
- deletes `src/utils/database/getDatabaseConnection.ts` when it still matches a template the
  practice shipped. the match ignores format, so a reformatted copy still counts
- keeps a copy the repo edited, and stamps a review pointer at its top
- deletes the old `getDatabaseConnection.integration.test.ts` on a template match. an edited copy
  is kept and repointed
- repoints every importer under `src/` onto `getOneDatabaseConnection`, both the module path and
  the factory name. a `getDatabaseConnection` imported from another module is left alone
