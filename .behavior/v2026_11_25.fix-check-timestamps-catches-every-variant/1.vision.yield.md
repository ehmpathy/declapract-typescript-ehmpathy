# 1.vision — the forbid-timestamps hook refuses every time-of-day variant

notation: `hh` hour · `mm` minute · `ss` second · `h` one-digit hour · `YYYY-MM-DD` date.
this file holds no real clock: the hook it describes scans it.

## what this builds

`check.timestamps.sh` reads a clock as a clock when its **shape** says so (a colon) or when an
**anchor** says so (a lead `T`, a date before, a zone or meridiem after). today it knows only the
colon and the `T`. this work adds the other anchors and the one-digit hour, as named forms in one
alternation:

| form | halts | anchor that makes it a clock |
|------|-------|------------------------------|
| `T` + colon clock | `…Thh:mm`, `…Thh:mm:ss.fffZ` | lead `T` (extant) |
| `T` + dash clock | `…Thh-mm-ssZ` | lead `T` (extant) |
| colon clock | `hh:mm`, **`h:mm`** | the colon; left edge spares `file.ts:nn:nn` and port maps |
| **zoned colon clock** | `key:hh:mmZ` | a zone rules out the line:col sense, so no left edge is owed |
| **zoned clock, any join** | `hhmmZ`, `hhmm UTC`, `hh-mm-ssZ`, `hhHmmZ`, `hh.mmZ` | `Z` / `UTC` / `GMT` |
| **date + basic iso** | `YYYYMMDDThhmmssZ`, `YYYY-MM-DDThhmm`, `YYYY-MM-DDThh` | a date, then `T` |
| **date + clock** | `YYYY-MM-DD hhmm`, `YYYYMMDD hhmm`, `YYYY-MM-DD_hh-mm-ss`, `YYYY-MM-DD hh.mm` | a date before (separated or basic; two shapes, no backref) |
| **`h`-mark clock** | `hhhmm`, `hhHmm` | `h` or `H` between two-digit parts |
| **meridiem clock, any join** | `h:mm pm`, `hpm`, `hh a.m.`, `h-mm pm`, `hhmm pm` (12-hour) | am / pm |

the halt message, the exit code, the `.ts`/`.sh` skip, and the duration strip do not change.

### why it works

each new form demands an anchor, and each anchor is a marker that only a clock carries. the shapes
with no such marker (`hh.mm`, `hh-mm-ss`, bare `hhmm`) stay out, because years, versions, decimals,
`dd-mm-yy` dates, and page ranges share them (F3). edges on both sides keep each form out of hashes,
base64, and ids.

### the proof it holds

- **every variant halts.** a probe of 34 time-of-day lines: the shipped hook passes 23. the draft
  pattern passes 4, each named in inventory rows 18–21 as a shape that cannot be told from a non-clock.
- **dates and look-alikes pass.** 30 non-clock lines (dates, line:col, ports, ratios, versions, page
  ranges, hour counts, hashes, base64, durations, route slugs): 1 halts, the scale ratio `1:nn` (F1).
- **no new false positives at scale.** both patterns over all 2674 tracked files of this repo: the
  shipped hook finds 9 lines, the draft finds 12. the 3 new hits are real leaks: one-digit meridiem
  clocks in `.behavior/v2026_08_31.fix-lambdas-3/5.1.execution.from_vision.yield.md` (lines 1033,
  1038, 1048). zero new hits are false.

the probe is paved for the next traveler: `rhx check.timestamps.probe --cases <file>|@tracked [--hook <path>]`.

## the outcome world

**before.** a clone pastes a log line with `hhmmZ` into a yield, or titles a section
`YYYY-MM-DD hhmm`, or notes a quota that resets at `h:mm` am. the hook passes all three. the hour a
human sat at a desk ships to every clone and fork of every repo the practice reaches.

**after.** the same commit halts with the message every dev already knows. the dev masks to `[time]`
and moves on. a changelog date, a stack ref, a port map, a version, a route slug: all pass, silent.

**the aha.** the hook was never short on patterns; it was short on **anchors**. once the rule reads
"a clock shape, or a number a clock marker vouches for", every variant on the wish's list collapses
into ten named forms. variants beyond the list stay itemized as known gaps in the inventory (rows
22a–22n), each with its reason; the false-positive line stays where it was.

## mental model

a dev would say: "the commit hook blocks any time of day in a doc, not just the iso kind."
analogy: a spam filter that learned the obfuscated spellings. the dev's term is "time" or "clock";
ours is "timestamp" in the halt message. the message stays: it is locked by a snapshot and known.

## evaluation

- **goals.** every variant the wish names halts (rows 1, 2, 3). the full set is enumerated by a
  dimensional walk, not a free-list. a date alone still passes. each form gets its own test row.
- **pros.** no new message, flag, or exit code. one regex alternation. a privacy leak class closes
  at the source, for every consumer, on the next `declapract apply`.
- **cons.** a scale ratio `1:nn` or a verse ref `n:nn` now halts (F1). three unanchored shapes still
  pass (F3). the pattern is longer, so it earns a named-form layout with one comment per form.
- **edges.** a yaml key with no space (`at:hh:mm`, no zone) still passes, to spare line:col refs;
  with a zone it halts. a page range `nnnn-nnnn` passes because offsets are not accepted as an
  anchor for a basic clock.

### assumptions

- consumer repos look like this corpus (see the [research] item above).
- clocks are written in english or iso notation. a word-marked clock in another language
  (`hh Uhr mm`, `hh時mm分`) passes; the word list is unbounded and the corpus holds none
  (inventory row 22a).
- bare `24:00` (iso end-of-day) passes; the hour class stops at 23 to keep scores like `nn:nn` out.
  a dated or zoned `24:00` still halts (row 22b).

## what is awkward?

- the wish's own example `hh:mmZ` halts in plain prose today; it slips only after a colon (F5). the
