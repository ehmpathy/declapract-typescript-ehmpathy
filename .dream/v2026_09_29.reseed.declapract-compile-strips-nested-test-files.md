# 🌙 dream: declapract compile strips nested test files from a practice

kind: reseed · owner: ehmpathy/declapract · caught 2026-10-14

## .the cue that fired

lane L5 of `v2026_09_29.fix-absorb-recent-upgrade-reports` wrote clamps over every declaration in
the practice tree, and had to skip files that are not declarations at all.

## .the gap, precisely

`declapract compile` does not strip `*.declapract.integration.test.ts`, `.test/` fixture dirs, or
`__snapshots__/` nested inside a practice. they ship in the published package and are read as
declarations — e.g. a fixture `package.json` under `.test/assets/` sits where a best-practice
`package.json` would.

## .the shape of the fix

compile (and the declaration reader) skip any path segment that starts with `.test` or is
`__snapshots__`, and any file that ends in `.test.ts` / `.integration.test.ts` / `.snap`. a test in
declapract: compile a practice that holds each, assert none is emitted or read.

it lives in another repo (route seed S5: no work in other repos).
