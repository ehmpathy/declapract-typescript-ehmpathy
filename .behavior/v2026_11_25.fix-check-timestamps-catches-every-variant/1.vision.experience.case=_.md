# 1.vision.experience.case=_ — the inventory

one row per cell of `1.vision.experience.dimensions.md`. `today` = the shipped hook; `after` = this work.
feel: happy (the dev is let through) · sharp (the dev is halted). care = freq × cost of a break.
a missed form ships a leak that git history never takes back (cost ∞), so every slipped form is a
critipath at any frequency. a false halt costs one cheap rewrite, so a look-alike path is criti only
where it is walked on most commits (dates, line:col refs).

verdicts: demoed · itemized (a real path, no demo owed) · forbidden (nurture: a rule bars it) ·
impossible (nature: the form cannot occur). a "pass row" is an itemized happy path the hook must
let through.

demos:
- case=1 → `1.vision.experience.case=1.slipped-form-halts.md`
- case=2 → `1.vision.experience.case=2.lookalike-passes.md`
- case=3 → `1.vision.experience.case=3.scale-ratio-halts.md`
- case=4 → `1.vision.experience.case=4.upgrade-meets-old-text.md`
