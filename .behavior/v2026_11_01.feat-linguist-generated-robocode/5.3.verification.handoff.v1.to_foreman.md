# 5.3.verification handoff v1 → foreman

## .the ask

three rows the wish owes that a driver cannot close alone. each needs the branch on github, and the last needs a human with a clock.

1. **the live render (Q7–Q10).** push this branch and open a pr. confirm:
   - folded: a file under `src/access/daos/`, a `*.test.ts`, a route `*.stone`
   - open: a `*.snap`, a `*.yield.md`, a `.radio/` record
   - a folded file opens in one click
2. **code search (Q6).** after github indexes the branch, search the repo for a string that exists only in a `*.test.ts` on it, e.g. `then('git diff still counts the cut line`. record found or not found. github's docs say only "vendored and generated code is excluded"; they do not say whether `linguist-generated` counts.
3. **the pilot (case=5).** pick one pr in a repo that adopts the practices. time a review of it with the fold off, then with the fold on (or two comparable prs). report the two numbers: minutes before, minutes after.

## .what i tried, and why each falls short

| approach | why it falls short |
|----------|--------------------|
| prove the fold at the git level | done: `git check-attr` reads `set` / `unset` / `unspecified` per path, through `executeApply` on all five declarers (`src/gitattributesDeclarers.declapract.integration.test.ts`, 22 pass). git decides the attribute; github decides the render, and no local tool runs github's renderer |
| read linguist's source for the render rule | done by peer reviews r010 and r011: `generated.rb` honors `linguist-generated` and has no snapshot rule. that is the rule, not the rendered pr the wish names |
| push the branch myself | a push needs a commit. this route asks for no commit at 5.3 (`rule.forbid.commits-the-route-did-not-ask-for`), and commit quota is the foreman's grant |
| time a review myself | the pilot measures a human reviewer's minutes; a driver's read time is not that number |

## .why this is foreman-only

- rows 1 and 2 need the branch on github: a commit and a push, which this stone does not sanction and whose quota the foreman holds
- row 3 is a human measurement by definition

## .what is already proven, so the foreman need not redo it

- every path the wish names reads the right attribute in git: daos and sql tables `set`; `*.test.ts` and `*.test.tsx` `set`; route trail `set`; `*.yield.*` and `.radio/**` `unset`, even when named like a test; `*.snap`, `sql/init`, and domain source `unspecified`
- a repo-own un-fold line wins over the managed folds, after an upgrade and after a declarer is dropped
- a fold hides no line from `git diff` (`0 1` on a cut test line)
- all suites green: see `5.3.verification.yield.md`
