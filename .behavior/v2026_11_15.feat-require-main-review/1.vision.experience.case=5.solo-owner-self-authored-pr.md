# case=5: a solo owner authors their own pr

feel: sharp · care: alterpath. rare: the fleet's prs are authored by seaturtle[bot], and 54 of the
55 `uladkasach/*` repos leave main unprotected (census), so few solo-owner repos run this practice.

## .narrative

in a `uladkasach/*` repo, the owner is the only human with write. they author a pr by hand.
github forbids an author's approval of their own pr. `enforceAdmins: true` forbids an admin
bypass. the pr cannot merge.

the way out is the extant fleet flow: the bot authors and the owner approves. or the owner makes
a deliberate settings change, which `enforceAdmins` already names as the only exception.

## .bdd sketch

```
given main requires one approval, enforceAdmins = true
  given a repo with one human with write
    when [t0] that human opens a pr and its checks pass
      then the pr cannot merge (no non-author can approve)
    when [t1] the same change is opened by seaturtle[bot] instead
      then the human approves and it merges (case=2)
```
