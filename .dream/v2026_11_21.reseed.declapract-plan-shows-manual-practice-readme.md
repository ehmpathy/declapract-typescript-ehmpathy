# 🌙 dream: declapract plan shows the readme of a manual practice it flags

kind: reseed · owner: ehmpathy/declapract · caught 2026-11-21

## .the cue that fired
a 5.3 peer review of the ts7 pr graded `emitManualFixNoticeOnce` as a fix in a non-owner: each manual check writes its remedy to stderr because `declapract plan` reads a practice's `.declapract.readme.md` but never prints it.

## .the gap, precisely
- a `FIX_MANUAL` flag names the file and the practice, never the move a human must make
- the move sits in the practice readme, which the plan loads and drops
- so each manual check in this repo hand-rolls a stderr notice (`emitManualFixNoticeOnce`), and `.npmrc` did the same before it

## .the shape of the fix
- in declapract: under each `FIX_MANUAL` line, print the practice readme's `## .fix` section (or its first paragraph), once per practice per plan
- then, here: drop `emitManualFixNoticeOnce` and its call sites; the readmes already hold the move

## .why it is not done in this round
the cause lives in another repo. the notice here is additive (the check still returns or throws its verdict), so it ships no harm while the upstream fix waits.
