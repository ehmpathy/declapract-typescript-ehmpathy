inventory rows 14, 15. feel: happy. care: critipath (every commit meets it).

## .narrative

a dev commits a changelog with `YYYY-MM-DD`, a route dir named `vYYYY_MM_DD.slug`, a stack ref
`file.ts:nn:nn`, a port map `nnnn:nnnn`, an aspect ratio `n:n`, a version `n.n.n`, and a sentence
about `nnnn hours` of compute. none is a time of day. the commit lands, silent, as it does today.

this path is the reason a wider pattern is safe. a hook that halts a date or a stack ref trains every
dev to bypass it, and a bypassed hook guards no one.

## .the test shape

the pass table (`[case14]`) gains rows for the new look-alikes that border the new forms: a basic
date (`YYYYMMDD`), a route slug date, a dotted release date, a page range `nnnn-nnnn`, a count of
hours, a duration `hhhmmm`, a token with `hhmmZ` inside it, `Tnnnn` as an id. the wish's own guard,
"a date with no time of day still passes", is `[case6]` plus these rows.

the corpus read backs the table: the fixed pattern over all 2674 tracked files of this repo adds
zero false positives (see the yield's groundwork).
