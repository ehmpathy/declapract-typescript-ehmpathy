# case=10 — an expo app knows which access it was built with

critipath · feel: happy · cells: A=adopter × B1 × C1/C2 × D1, A=system × B1 · issues: #618, #619, #620, #621, #610, #653, #676

## .narrative

before: in app-protools-native, `start:cold:prep` and `start:cold:prod` were byte-identical, and both
reached prod. the deploy compile step never passed the access input, so a bundle built for prep
guessed its access from whatever the env held. `expo export` reused one metro cache across every
access, so a prep transform could ship inside a prod bundle with no error. the local https proxy
started before its target listened and hung on the first request. the expo acceptance run timed out
against a cold livedb, since the wake shipped only in the node practice and its gate read a tunnel
config an expo repo never has. and when the upgrade flipped the repo to `node-linker=hoisted`, two
versions of one package fought silently for the top slot.

after: each cold command sets its own `ACCESS` and builds before it serves. `build:web` is
`ACCESS=${ACCESS:-prep} npx expo export --platform web`, and `metro.config.js` keys its cache dir on
`ACCESS` + the app config, so a prep build and a prod build never share a transform while a warm
rebuild stays warm. the deploy compile step passes `ACCESS` from its input. each proxy command waits
on its target port before it listens. the expo test prepares wake the prep livedb through the gateway before the
run. the hoisted flip prints, once, each package with more than one version in the lockfile and the
`pnpm.overrides` remedy.

## .[tn] sketch

```
given('[case1] an expo app one release behind')
  when('[t0] declapract apply')
    then('start:cold:prep and start:cold:prod differ, and each names its own ACCESS')
    then('build:web defaults ACCESS to prep')
    then('metro.config.js gains a cacheStores dir keyed on ACCESS + app config, and its own lines stay (#676)')
  when('[t1] npm run start:cold:prep')
    then('the served bundle reads ACCESS=prep')
  when('[t2] ACCESS=prod npm run build:web, right after a prep build')
    then('the export reads a prod cache dir, and the bundle holds no prep transform (#618, #676)')
  when('[t3] npm run start:cold:proxy before the cold server listens')
    then('the proxy waits on port 3000, and the first request is served, not hung (#676)')
  when('[t4] declapract apply again')
    then('metro.config.js is unchanged, with one cacheStores block')
  when('[t5] this repo\'s tests run')
    then('a clamp pairs each start:cold:<env> with its start:hot:<env>, and both set the same ACCESS (#653)')

given('[case2] the deploy workflow with inputs.access = prep')
  when('[t0] the web compile step runs')
    then('the step env holds ACCESS=prep, and the bundle reads prep')

given('[case3] an expo acceptance run against a cold prep livedb')
  when('[t0] npm run test:acceptance')
    then('the prepare wakes the livedb first, and no test times out on a cold start')
  when('[t1] the same run with ACCESS=prod')
    then('the wake refuses prod, as the node practice does')

given('[case4] an expo repo whose lockfile holds two versions of one package')
  when('[t0] declapract apply flips node-linker to hoisted')
    then('stderr lists the package, both versions, and the pnpm.overrides remedy, once')
  when('[t1] declapract apply again')
    then('stderr prints no contention set')
```

## .the aha

a build that does not know its access will guess prod.
