# case=5: pilot measures one pr

cells: p1 (P = same-diff-twice) — happy · critipath (the wish names it as done)

## .narrative

sam runs the pilot. the wish wants two numbers, and sam wants them honest.

sam opens pr #748 as it renders today: 78 files, most of them a route sam did not write. sam starts a timer and reviews the pr the way it would be read on any day. the stone prompts scroll past, then the guards and the 250-line `passage.jsonl`, then the 884-line integration test. the timer stops at the last file. sam writes the number down.

next, sam pushes a scratch branch atop the pr head, with the new `.gitattributes`, and opens its compare page. the files list is the same 78 rows, but most now read "load diff". the route opens on its yields and its `.radio/` records. the test file is one folded row, `+884 −0`. the snapshots and the source sit open. sam restarts the timer and reviews again. the read is shorter, and sam notices one cause is not the fold: sam has read this diff once already.

the clone hands sam the proxy beside it: lines open by default, before and after, computed from `git diff --numstat` and `rhx git.attr.get` on each path. that number needs no stopwatch, and a rerun gives the same answer.

sam writes the report: the pr, the two review minutes, the proxy, and one plain caveat. the second read had memory on its side. a fairer pilot uses two prs (p2) or two reviewers (p3), and sam offers both to the wisher (Q4b).
