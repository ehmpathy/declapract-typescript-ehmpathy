# case=7: maintainer applies the practice to this repo, then asks git what folds

cells: mt1 · mt4 · dd2 — happy · critipath

## .narrative

kai maintains declapract-typescript-ehmpathy. a change to the tests-any section lands in `src/`. this repo consumes its own practices, so its own `.gitattributes` now lags the practice output, and the self-check goes red.

kai does not hand-edit the file. kai runs `rhx declapract.self.apply --practice tests-any --file .gitattributes`. the skill builds `dist/`, applies that one practice to that one file in an isolated root, and copies the file back. it ends:

```
🐢 righteous! applied
   ├─ .gitattributes: rewritten
   └─ vs HEAD: 1 file changed, 1 insertion(+)
```

a second run says `.gitattributes: unchanged, already converged`, so kai knows the first one landed and the second did naught.

then kai asks git which paths fold, on real paths of this repo:

```
$ rhx git.attr.get --attr linguist-generated --paths 'src/a.test.ts src/a.ts'
src/a.test.ts: linguist-generated: set
src/a.ts: linguist-generated: unspecified
```

the test folds; the source stays open. the self-check goes green.
