# case=8 — lambda handlers and their callers move onto sdk-aws-lambda 0.7.2

critipath · feel: happy, one sharp stop · cells: A=adopter × B1/B2 × C1/C3 × D1, A=system × B1 · issues: #646, #650, #640, #631, #636, #666, #670, #680

## .narrative

before: svc-notifications' handlers sat on `genLambdaEndpoint.for.apiGateway(` with
`invoke: async ({ event })`. the practice floor was 0.4.0, so the upgrade never moved them. its
acceptance tests called `simple-lambda-testing-methods`, an aws-sdk v2 caller that cannot read an
sso profile, so they failed on every laptop with sso creds. the migration guide still taught
`rawEvent`. its peer calls to svc-quotes used the ancient address but the contemp payload shape, so
every call to a pre-0.7 peer failed at the peer. and 0.7.0 itself rejected any handler that returned
an `IsoTimeStamp`, because its `FrozenDeep` type turned a branded string into an object.

after: sdk-aws-lambda 0.7.1 carries the primitive guard, and 0.7.2 frames a contemp api gateway
call right (sdk-aws-lambda#51). the practice floors at 0.7.2 (S21). apply rewrites
each pre-0.7 handler to `.forApiGateway(` / `.forAsk(` with `{ payload }`, and each acceptance test
to `runLambdaEndpoint.onSerialized` / `.onReferenced` and `asLambdaEvent.fromApiGateway`. each peer
call goes through `sdkAwsLambdaAskAncient`, which sends the ancient address and the ancient payload
struct together; it keeps one cast, documented inline, until sdk-aws-lambda#42 releases.
`sdkAwsLambdaEnvAccessAncient` returns the exact access set.

each rewritten apiGateway acceptance call takes the contemp default, with no struct, so its 400
answers the nested body. the same apply moves each 400 read in that file: `errorMessage` becomes
`error.message`, `errorType` becomes `error.class`. a read off a real http response stays flat,
since the wire answers the flat body to a caller with no `x-trail-exid`. a file that holds both
kinds is not rewritten; each flat read gets a marker that names the move (F39). biome now lints
`blackbox/`, and bans an import of `simple-lambda-testing-methods` (#666). a repo that patched
0.7.0 or 0.7.1 locally loses the patch file and its `patchedDependencies` key once the floor
reaches 0.7.2 (#670). and `pnpm.allowUnusedPatches`
and `pnpm.ignorePatchFailures` are set, so no patch halts the install or the upgrade (#680, S10). a
stale patch on any package — keyed off the lockfile's resolved version — is retired by the same kind
of fix that retires the 0.7.0 patch (F56); a patch that no longer applies prints a warn.

the sharp stop: a test that asserted a thrown error through `getError(...)` on the old invoker gets a
marker, since `.onReferenced` returns a fault as a value. the marker names the change.

## .[tn] sketch

```
given('[case1] a service on sdk-aws-lambda 0.6 with simple-lambda-testing-methods in its acceptance tests')
  when('[t0] declapract apply')
    then('sdk-aws-lambda is 0.7.2 and simple-lambda-testing-methods is gone from package.json')
    then('each handler calls forApiGateway or forAsk and reads { payload }')
    then('each acceptance test calls runLambdaEndpoint and imports from sdk-aws-lambda')
    then('each getError assertion over the old invoker has one @declapract:review line above it')
  when('[t1] tsc --noEmit')
    then('green, with a handler that returns an IsoTimeStamp')
  when('[t2] declapract apply again')
    then('zero files change')
  when('[t3] the acceptance suite runs against a forApiGateway endpoint')
    then('no call passes a struct, a 400 answers 400, not a 500, and its rewritten read of error.message passes')
  when('[t3.1] a test file that also reads an http response')
    then('no read is rewritten, and each flat read has one @declapract:review line above it')
  when('[t4] npm run test:lint with a blackbox test that imports simple-lambda-testing-methods')
    then('red at noRestrictedImports, with the file and line')

given('[case4] a repo with pnpm.patchedDependencies["sdk-aws-lambda@0.7.0"] and patches/sdk-aws-lambda@0.7.0.patch')
  when('[t0] declapract apply')
    then('the key and the patch file are gone, and sdk-aws-lambda is 0.7.2')
  when('[t1] the same repo, with a patch keyed on sdk-aws-lambda@0.7.2')
    then('that patch stays')
  when('[t2] a repo with a stale patch on another package, and pnpm.overrides already set')
    then('package.json gains pnpm.allowUnusedPatches and pnpm.ignorePatchFailures, and pnpm.overrides stays (#680)')
    then('the stale patch entry and its file are gone, and plan named the delete as a fix line (F56)')
    then('pnpm install passes; no ERR_PNPM_UNUSED_PATCH')
  when('[t2.1] a patch keyed on the resolved version that no longer applies')
    then('pnpm install passes with a warn that names the failed patch, and the upgrade continues')
  when('[t3] declapract apply again')
    then('package.json is unchanged')

given('[case2] a service that calls a peer still on the ancient address')
  when('[t0] declapract apply')
    then('the call goes through sdkAwsLambdaAskAncient')
    then('the event the peer receives is the bare ancient payload, never { event, trail }')

given('[case3] an unattended ci runner on the adopted service')
  when('[t0] the acceptance job runs')
    then('no aws-sdk v2 caller is loaded')
```

## .the aha

a floor is only as good as the release under it — so the floor waited until the release shipped.
