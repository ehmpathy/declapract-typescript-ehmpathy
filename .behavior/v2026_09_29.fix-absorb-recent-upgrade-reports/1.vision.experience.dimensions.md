# 1.vision.experience.dimensions

the experience space this wish touches, factored into orthogonal axes. the product is walked in
`1.vision.experience.case=_.md` § the walked product.

## .the dimensions

| # | dimension | values |
|---|-----------|--------|
| A | **actor** | `adopter` — a repo mid-upgrade (`declapract plan` / `apply`) · `reporter` — the repo that filed the issue, which watches for it to land · `maintainer` — this repo's next author · `system` — an unattended ci runner (an adopter's or this repo's), no human at the keys |
| B | **defect class** (what the practice does wrong) | `B1 emits-broken` — ships a template that fails a gate the practice itself declares · `B2 fix-breaks` — a fix fn rewrites src or deps and leaves the tree unbuildable · `B3 check-lies` — a check reads green on a tree that violates it, or never fires · `B4 no-converge` — a second `apply` still changes files · `B5 local-friction` — a gate that fails only off ci · `B6 prose` — a doc or comment that misleads · `B7 feature` — a new capability, no defect |
| C | **delivery to an extant repo** | `C1 equals` — whole-file template; the next `apply` overwrites · `C2 merge` — a CONTAINS check with a fix fn that must merge the new key in · `C3 new-bad-practice` — detect + rewrite src that no template owns |
| D | **disposition** | `D1 fixed` — lands in this round, names its issue · `D0 fixed-before` — a prior commit fixed it and only referenced it, so the issue closes with that commit · `D2 held` — open, with one comment that names the shipped work outside this repo it waits on (seed S3: app-protools-native's latest work; seed S5: an unshipped upstream pave, e.g. #682). no other open value exists: seed S2 forbids a deferral for size or taste |
| E | **feel on the next upgrade** | `happy` — the upgrade passes the gate it used to trip · `sharp` — it still trips, but loud, and names the fix |

E is closed at these two values. a case header may add a clause of prose after the value (e.g.
"sharp — a halt that names the fix"); the value itself is always one of the two.

## .why the axes are orthogonal

- **A ⟂ B** — who meets a defect does not decide what the defect is; the same B2 (#642) is met by
  an adopter at `tsc`, by a reporter as an issue, and by `system` as a red ci job.
- **B ⟂ C** — the defect class does not fix the delivery path. B5 spans C1 (#647, jest configs) and
  C2 (#639, a merge fn); B2 spans C3 (#642, #643) and would span C1 if the broken dep were a template.
- **B ⟂ D** — any class can sit in either disposition: B1 sits in D1 (#632) and D0 (#613, a
  template that failed its own parse gate).
- **C ⟂ D** — delivery is how a fix travels, disposition is when it traveled (this round or before).
- **D is skewed by decree, not by construction.** seed S2 removed every deferral for size or taste;
  seeds S3 and S5 admit only a hold on work outside this repo. so 108 of 126 cells share `D1`, 9
  sit in `D2`, 9 in `D0`. the reporter's experience differs across all three (case=4 `[case1]`–`[case3]`).
- **E ⟂ B, C** — within one class the feel varies with the fix shape: B2 is `happy` at #642 (a dep
  added) and `sharp` at #643 (flag + marker, since the move needs a human).

hidden-dimension check: a row or column that cannot occur would expose a latent axis.
- `A=system × D0` — a ci runner has no experience of a fix that already shipped. empty, but that
  follows from the fact that `system` meets bytes, not issues; recorded as impossible in the inventory.
- `B7 × care=crit` — a feature can be critipath (#622: every adopter's acceptance run pays the
  rebuild it removes). so care is not a function of B; it stays a label per row.
- `A=system × D2` — a ci runner meets a held issue's bytes unchanged, so its experience equals the
  pre-round one. empty for the same reason as `A=system × D0`; recorded as impossible.
- `C3 × B1` — a template that fails its own gate is always C1 (the template owns the file). this is
  the one near-dependency: C is partly determined by *who owns the file* (template vs adopter src).
  surfaced as the latent axis **file owner** (practice | adopter). it is not added as a sixth axis,
  since C already encodes it one-to-one: C1/C2 ⇔ practice-owned, C3 ⇔ adopter-owned.

## .the walk — which products are real

- **A × D** is the close contract: every issue lands in exactly one D cell, and the `reporter` sees
  a closed issue that names the commit (D1), cites the older commit (D0), or an open issue whose one
  comment names what it waits on (D2). no issue stays open silent.
- **A=system** is real only on fixes that touch a gate ci runs: B5 (#639, #647 — the ignores are
  inert in ci; #645 — the format job needs no terraform), B3 (#649 red on `.only`; #611/#612 skipped
  in ci as before), B1 (#632, #627 at `tsc`; #619 at the deploy compile), B7 (#622 the stamp skip),
  B2 (#642 — a fix fn that drops a dep leaves an unresolved import that ci's `tsc` meets on the
  adopter's next pr; itemized in the inventory).
- **B × C** decides whether a fix reaches an extant repo at all. `C1` reaches it for free on the
  next apply. `C2` reaches it only if the fix fn merges (#639 is the measured miss; #608, #638, #628
  are the same trap). `C3` is the only path for src the practice never declared (#642, #643, #626,
  #629).
- **B × E** is the critipath axis: `B1`, `B2`, `B4` fixed = `happy`; where a fix cannot be safe
  without a human (an arity move, a param copy, an anchor miss), the fix is a loud `sharp` stop
  that names the move — never a silent pass.
- **A=maintainer × B1** is its own cell: a clamp in this repo so the same class cannot ship again
  (e.g. the best-practice templates are not type-checked here — how #632 shipped).

## .forbidden cells

- **D1 × a fix that narrows a practice a service relies on** — forbidden by the wish ("no fix
  narrows or silently drops a practice"). rejection invariant: a fix may tighten a check only where
  the tighter form is what the practice already promised.
- **D1 × C2 with a fix fn that seeds only fresh files** — forbidden: the fix would land for new
  repos and never for the reporter.
- **B6 × D1 that states a shape no published version carries** — forbidden (#640's own caveat); so
  #640's guide teaches the 0.7.1 shape, which is published.
- **D1 × a floor on an unpublished release** — forbidden by seed S5 ("only pull in what is already
  done"). such a fix is D2 until the release publishes.
- **any issue × an open disposition other than D2** — forbidden by seed S2. a D2 hold names work
  outside this repo; size, taste, or effort never qualify.
