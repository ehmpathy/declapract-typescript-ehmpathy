# 🌙 dream: repo-local skills print `--help` as a treestruct, not a raw header dump

kind: chore · owner: declapract-typescript-ehmpathy (`.agent/repo=.this/role=any/skills/`) · caught 2026-11-25

## .the cue that fired
l3 peer review of the timestamps fix: the probe's `--help` snapshot is the source's `####` comment
banner, `# ` on every line, with no house treestruct.

## .the gap, precisely
the repo-local skills print `--help` via `sed -n '/^####/,/^####/p' "$0"`. the probe and
`route.concerns.dispose` both do; the latter also prints `set -euo pipefail` past the end rule.

## .the shape of the fix
one shared help printer for the repo-local skills: read the header, drop the `#` rules and prefixes,
render `🐢` + `🐚 <skill>` and the `.what`, usage, options, guarantee sections as a tree; move each
skill to it in one pass, and snapshot each `--help`.

## .why it is not done in this round
a change to every repo-local skill's help is its own pr; the probe alone would make it the odd one.
