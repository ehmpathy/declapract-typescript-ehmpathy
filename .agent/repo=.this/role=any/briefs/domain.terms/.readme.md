# domain.terms — this repo's glossary

one cluster per **word** that composes a domain object or operation this repo declares. a word is
paved once and reused: the adj `ordered` serves `ignoresOrderedForGitignore` and every future
`*Ordered`, so a new declaration usually **cites** an extant cluster rather than adds one.

## the rules that rule this dir

| rule | what it demands |
|---|---|
| `rule.require.domain-term-itemization` | a term that composes a declared dobj/dop gets a cluster here |
| `rule.forbid.domain-term-synonyms` | a **contract** uses the canonical word — adhere, or open a dispute. never drift |

a **contract** is a dobj/dop name, an internal signature, or a published interface. a *comment* may
use a synonym to describe the concept from another angle; that is allowed, and each cluster lists
the synonyms it forbids so the map stays legible.

## the shape

`term=<x>._.choice._.md` (say — lean, always booted) + `term=<x>._.choice.reason.md` (ref — deep,
on demand, **required**) + optional `term=<x>._.choice.example=<abc>.md`.

full shape: `template.domain-term.md`. dispute pattern: `howto.domain-term-disputes.[guide].md`.
why the obsession at all: `im_an.obsessive_learner.for.domain.terms.md`.

## the terms paved so far

| term | kind | what it names |
|---|---|---|
| `sortable` | adj | a declared line whose position is **inert**, so it may be sorted freely |
| `ordered` | adj | a declared line whose position **carries load**, so it is held out of the sort |
| `convergence` | noun | two+ declarers of one file emit a byte-identical result, in either order |
| `oscillation` | noun | its antonym — each declarer rewrites the file into a shape the others reject |
| `declaration` | noun | a `*.declapract.ts` module — executed HERE, may import `src/utils/` |
| `template` | noun | a `best-practice/` file **copied to a consumer** — its imports are looked up there |
| `declarer` | noun | a **practice** that holds a declaration for a given file — one file may have several |

⚠️ **`declarer` is the one term here paved by exception, and the exception is narrow.** it names no
identifier (`grep src/**` → zero matches), so `rule.require.domain-term-itemization` would not ask
for it. it is paved because **the glossary cannot state its own terms without it** — `convergence`
is defined as agreement *between declarers*, distinct from a declarer with itself. read its
`.reason` before you cite it as precedent for another non-identifier term.

two pairs, deliberately. `sortable` ↔ `ordered` is git's split, and to name both makes an author's
choice of constant *the* classification. `declaration` ↔ `template` is declapract's split, and both
kinds sit in the same directory — a distinction invisible in a file tree, and one whose conflation
already cost a wrong design decision that propagated to five artifacts before review caught it.

each pair exists because **an unnamed half is an invisible decision**. see each `.reason` for the
evidence and the disputes that settled it.
