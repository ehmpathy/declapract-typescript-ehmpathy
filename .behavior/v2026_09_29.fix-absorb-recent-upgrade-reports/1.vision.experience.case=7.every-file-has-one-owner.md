# case=7 — every file has one owner, so apply converges and no fix is left behind

critipath · feel: happy · cells: A=adopter × B4 × C1/C3 × D1, A=maintainer × B4 · issues: #630 (owner axis), #607, #658

## .narrative

before: svc-chat's second apply still rewrote `config.schema.ts`, `getConfig.ts`,
`getOneDatabaseConnection.ts`, and `.husky/check.lockfile.sh`. each had two declarers in one
usecase: two EQUALS templates that disagreed, or a template and the `relative-imports` bad-practice
that rewrote it back. declapract applies fixes in practice-name order, so the later practice won each
pass, forever. app-protools-native saw the quiet cousin: a declared file with a shipped fix that
apply never touched, because one other check on that file had no usable fix, and core marks the
whole file as manual.

after: every file in a usecase has one owner. templates import through `@src/…`, so
`relative-imports` has no quarrel with them. the second owner of each fought-over file either gone,
or holds a check that accepts the owner's shape and writes only when the file is absent. the
declarations that could only ever fail (an EXISTS claim on a dir terraform-aws moves away) are gone.

a maintainer who adds a second declarer by accident sees this repo's test go red: per usecase, no
path has two declarers unless it is on the allowlist of files built to be shared (`package.json`,
`.gitignore`).

## .[tn] sketch

```
given('[case1] a lambda-service-with-rds repo one release behind')
  when('[t0] declapract apply')
    then('config.schema.ts matches the persist-with-rds shape')
    then('getConfig.ts, getOneDatabaseConnection.ts, sayHello.ts import via @src/')
  when('[t1] declapract apply a second time')
    then('zero files change')

given('[case2] an app-react-native-expo repo one release behind')
  when('[t0] declapract apply, then declapract plan')
    then('plan lists no file whose declared fix exists')
    then('.github/workflows/test.yml matches the one cicd-common template')

given('[case3] a maintainer who declares a file already owned by another practice in the same usecase')
  when('[t0] the maintainer runs this repo\'s tests')
    then('the multi-declarer clamp goes red and names the file and both practices')

given('[case4] every declaration with a fix')
  when('[t0] fix runs on a representative adopter input, then check runs on its output')
    then('check passes, so core never marks the file manual')

given('[case5] a lambda-service-with-rds repo whose config.schema.ts holds the database block (#658)')
  when('[t0] declapract apply --practice config')
    then('config.schema.ts keeps its database block: config\'s check passes on any superset of the base keys')
  when('[t1] declapract apply')
    then('config.schema.ts matches the persist-with-rds template, its one owner')
  when('[t2] this repo\'s tests run')
    then('the multi-declarer clamp lists config.schema.ts with persist-with-rds as owner')
```

## .the aha

a converged apply is not a lucky order — it is one owner per file, held by a test.
