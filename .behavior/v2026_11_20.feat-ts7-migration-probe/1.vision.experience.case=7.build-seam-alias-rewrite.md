# case=7 · ci builds a lambda service on typescript 7

feel: sharp · care: critipath · boundaries: 2 · actor: ci

## .narrative

kai pushes `svc-wavereports` after the ts7 upgrade (case=3). ci picks it up. `npm run build` runs `tsc`, then `tsc-alias`, which turns each `@src/*` specifier into a relative path. the tsconfig has no `baseUrl` now. ci sees the build exit 0 and moves to `test:acceptance`, which runs against the built contract. the handler loads `dist/contract/handlers/get.js`, whose `require("../../logic/getWaveReport")` finds its file. green. deploy proceeds.

the sharp edge sits in the middle of that walk. if `tsc-alias` could not map `paths` without `baseUrl`, the build would still exit 0. `dist/` would keep `require("@src/logic/getWaveReport")`, and the first cold start in prod would throw `Cannot find module '@src/logic/getWaveReport'`. an exit code cannot catch this, so two nets guard it, in order:

1. **before the practice ships.** the probe builds the walked lambda-service consumer under 7.0.2 and greps `dist/**/*.js` for `@src/` and `@/`. a hit makes the verdict `fails`. no adopter's ci ever meets the edge, and the pr names what broke:

   ```
   ✋ alias seam: 3 unrewritten specifiers in dist/ (tsc-alias 1.9.10, typescript 7.0.2)
      ├─ dist/logic/getWaveReport.js:4    require("@src/access/daoWaveReport")
      ├─ dist/logic/getWaveReport.js:5    require("@src/domain/WaveReport")
      └─ dist/contract/handlers/get.js:2  require("@src/logic/getWaveReport")
      fix: keep the floor at 5.x until tsc-alias maps paths without baseUrl
   ```

2. **after it ships, against a later regression.** where a repo's acceptance tests go through the built contract, ci's `test:acceptance` fails loud with `Cannot find module`, before deploy. where they import `src/` directly, this net is absent, which is why net 1 is the gate.

## .timeline

```
given('a lambda service on typescript 7.0.2, tsconfig.build.json with paths and no baseUrl')
  when('[t0] ci runs `npm run build`')
    then('tsc emits dist/; tsc-alias rewrites each @src/* specifier to a relative path')
    then('no @src/ or @/ specifier remains in dist/**/*.js')
  when('[t1] ci runs `test:acceptance` against the built contract')
    then('each handler loads; the suite passes; deploy proceeds')
  when('[t2] before the practice ships, the probe finds an unrewritten specifier in the walked consumer')
    then('the verdict is fails; no src/practices/ change ships; no adopter ci meets the edge')
    then('the pr names file:line, the specifier, the tsc-alias + typescript versions, and the fix')
  when('[t3] after it ships, a blackbox-tested repo meets a later tsc-alias regression')
    then('ci `test:acceptance` fails with Cannot find module, before deploy')
```
