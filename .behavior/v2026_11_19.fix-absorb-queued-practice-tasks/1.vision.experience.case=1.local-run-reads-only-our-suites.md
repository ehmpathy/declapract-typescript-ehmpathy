# case=1 — a local run reads only our suites (e1, e6)

## .narrative
a clone on a shared grove upgrades nheuron. its tree holds three kinds of `.agent/` dirs: `.agent/repo=.this/` (nheuron's own skills and their suites), `.agent/repo=ehmpathy/` (vendored roles, 21+ suites of their own), and host-local scratch — `.agent/.actors/` (a plugin marketplace with its own tests) and `.agent/.cache/` (rmsafe's trash, which holds a `.snap` whose basename matches a live suite). a `.temp/` dir holds a fixture another run left.

today, on 0.50.0, `test:unit` matches zero suites and passes under `--passWithNoTests`: the practice skips all of `.agent/`, so nheuron's own suites never run. on 0.49, the same run read `6 failed` from plugin tests and `1 snapshot file obsolete` from the trash.

after the upgrade, the run walks `src/` and `.agent/repo=.this/`, and only those. the trash `.snap` no longer pairs with its namesake. `test:lint` finishes in seconds, since depcheck no longer crawls the trash or `.temp/`. the clone reads green and means it.

the same afternoon, a second clone upgrades app-protools-native, an expo app. its jest configs come from `tests-expo`, not `tests-node`, and carry the same ignore. its run walks the same set: own suites in, host-local and vendored suites out.

## .timeline
```
given('an adopter on an actor host, after the upgrade')
  given('a suite under .agent/repo=.this/, a red suite under .agent/.cache/trash, a red suite under .agent/.actors/, a suite under .agent/repo=ehmpathy/, a red suite under .temp/')
    when('[t0] npm run test:unit')
      then('the .agent/repo=.this/ suite runs')
      then('no suite under .agent/.cache, .agent/.actors, .agent/repo=ehmpathy, or .temp runs')
      then('no snapshot in the trash reads as obsolete')
    when('[t1] npm run test:lint:deps')
      then('no dep is reported absent from a file under .agent/.cache or .temp')
      then('an import in .agent/repo=.this/ still counts')

given('an expo adopter (tests-expo configs) on an actor host, after the upgrade')
  given('the same set of dirs and suites')
    when('[t0] npm run test:unit')
      then('the .agent/repo=.this/ suite runs; no suite under .agent/.cache, .agent/.actors, .agent/repo=ehmpathy, or .temp runs')
```
