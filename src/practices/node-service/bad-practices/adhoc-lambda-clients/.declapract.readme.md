# adhoc-lambda-clients

## what

flags a hand-written lambda client — a `svc*.ts` under `src/access/sdks/` or the legacy
`src/data/clients/` that wraps `askLambdaEndpoint` — with a review marker on line one.

## why

a hand-transcribed client drifts from its peer's contract with no signal until a call fails at
runtime. `sdk-aws-lambda gen` emits a typed client from the peer's live contract, so drift becomes
a reviewable diff on the next re-run (#532).

## the paved path

```sh
npx sdk-aws-lambda gen --for svc-jobs --into src/access/svcs/ --env prep
```

move callers onto the generated sdk, then delete the hand-written file.

## scope

- marks only; the generated sdk changes the import shape a caller uses, so no rewrite is attempted
- a file that mentions `sdk-aws-lambda gen` anywhere (as the codegen banner does) is left alone
- a file already marked is left alone, so a re-apply is a no-op
