this bad practice detects relative imports that traverse up directories (`../`) and can be replaced with the `@src/` path alias.

why this matters:
- relative paths are fragile and break when files are moved or reorganized
- `@src/` alias provides stable, absolute imports from the src root
- enables easier refactoring and code navigation
- imports remain correct regardless of file location

what it catches:
- imports using `../` (e.g., `from '../utils/helper'`)
- deeply nested relative imports (e.g., `from '../../../domain/objects'`)

what it ignores:
- same-directory imports (`./`) which are appropriate for local modules
- files outside `src/` directory
- imports already using `@src/` alias

the fix automatically rewrites:
```typescript
// before
import { helper } from '../utils/helper';
import { thing } from '../../shared/thing';

// after
import { helper } from '@src/utils/helper';
import { thing } from '@src/shared/thing';
```

## two-pass migration + the `directory-structure-src` pair

a file still under a deprecated src dir (`logic/`, `data/`, `domain/`, `model/`, `services/`,
`__nonpublished_modules__/`) is **deferred** this pass — the rewrite is held to the next `declapract
fix` pass, once the file sits at its new path. this is because `directory-structure-src`'s
`old-*-dir` bad-practices RELOCATE that file in the same pass, and a relocate plus an in-place
rewrite of one file in one apply throws ENOENT on the unlinked source. both practices share the
guard via `src/utils/isDeferredToDeprecatedDirMove.ts`, so they cannot drift.

two consequences a consumer should know:

- **run `declapract fix` twice** on a repo that still holds deprecated-dir files: pass 1 relocates,
  pass 2 rewrites the moved files' imports at their new path.
- **this practice pairs with `directory-structure-src`.** the deferral only completes if
  `directory-structure-src` is also in the usecase to perform the relocate. every usecase that
  declares `typescript-any` today also declares `directory-structure-src`; keep them together, or a
  deferred file is never moved and its rewrite never fires.
