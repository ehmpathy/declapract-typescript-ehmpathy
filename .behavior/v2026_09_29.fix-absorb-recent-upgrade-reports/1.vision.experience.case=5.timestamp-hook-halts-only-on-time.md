# case=5 — the timestamp hook halts on every time of day, only on a time of day, with zero exemptions

critipath · feel: sharp — a halt that names the fix, by design · cells: A=adopter × B1/B3/B5 × C1 × D1 · issues: #641, #681, #684

## .narrative

an agent in svc-chat commits a route yield that names a log file `…T<hh>-<mm>-<ss>Z.log` and a line
"ran at <hh>:<mm> UTC". today both pass `check.timestamps.sh`, since its pattern requires seconds and
colons. each one is a privacy leak, shipped to every clone and fork. and
the hook's own header ("timestamps in snapshots") taught the agent that prose was out of scope.

two more defects ride the same file. a staged path with a non-ascii byte reached `git show` quoted,
so the hook exited 1 as a malfunction on a legal file; and git's stderr joined the scanned bytes.

after: the pattern catches minute-only iso, dash-separated iso, and bare clock times. the hook reads
raw paths (`core.quotepath=off`), scans only the blob, and writes to stderr behind its class:
`✋ ConstraintError: timestamps are forbidden in tracked files. remove them, zero exceptions`, with
the privacy reason beneath it, or `💥 MalfunctionError:` when a blob cannot be read.

the hook takes zero exemptions (S16). its header says so in capitals; `.ts` and `.sh` are skipped
only because they are code that computes time, and that skip may never widen. #684 asked to exempt
the achiever's `.goals/` ask log; the answer is no — the log must not hold a clock. a second hook,
`check.timestamps.lock.sh`, runs first on every commit and halts while the timestamp hook differs,
on disk or in the index, from the blob id the practice declared: "revert the hook, zero exceptions —
remove all timestamps". a softened hook cannot be committed.

the other sharp side to guard: a hook that halts a commit on `src/foo.ts:42:7`, a `5432:5432` port
map, `PT12:30:00`, a `3:1` ratio, or a markdown table row blocks every dev on every commit. so the
pass-table is as much the contract as the halt-table.

## .[tn] sketch

```
given('[case1] an agent in svc-chat with a route yield staged that holds a time of day')
  when('[t0] the agent commits, with each of: <hh>:<mm> · <hh>:<mm>:<ss> · T<hh>:<mm>Z · T<hh>-<mm>-<ss>Z in the yield')
    then('the agent sees the commit halt, with "timestamps are forbidden" and the privacy reason')
    then('the agent reads the file and line of each hit')
  when('[t1] the agent removes each time and commits again')
    then('the commit lands')

given('[case2] an agent with a staged doc that holds no time of day')
  when('[t0] the agent commits, with each of: PT12:30:00 · 2026-09-20 · src/foo.ts:42:7 · 5432:5432 · 3:1 · |:---|:---:| in the doc')
    then('the commit lands on the first try, with no halt')

given('[case3] a staged file at a non-ascii path (#681)')
  when('[t0] the file holds a datestamp only')
    then('the commit lands; no false MalfunctionError')
  when('[t1] the file holds a clock time')
    then('stderr shows ✋ ConstraintError with the raw path and line, and the commit halts with exit 2')

given('[case4] a staged .route/x/.goals/asks.inventory.jsonl that holds a pasted shell prompt clock (#684)')
  when('[t0] the agent commits')
    then('the commit halts, as for any other file — no path is exempt')

given('[case5] an agent that hand-edits check.timestamps.sh to add an exemption (S16)')
  when('[t0] the agent commits')
    then('check.timestamps.lock.sh halts with "revert the hook, zero exceptions — remove all timestamps"')
  when('[t1] the agent runs `npx declapract apply --practice husky` and commits again')
    then('the hook is restored, the lock passes, and the scan runs with no exemption')
```

## .the aha

a guard earns trust by what it lets through as much as by what it stops — and by the fact that no
one can quietly loosen it.
