# case=3: pg-pool moves the fallback line, and the patch no longer fits

covers inventory #7, #8, #9, #33 (via-pg), #16, #17, #18, #36 (direct), and #21 (maintainer).

## narrative

**the maintainer meets it on the next ci run here.** pg-pool ships a release that rewrites the `this.Client = ...`
line. the next ci run of declapract-typescript-ehmpathy installs it fresh in the usecase walk; until a scheduled run
lands (F8 dream), an adopter who re-locks first meets it before the maintainer does. the `[t3]` step goes red on
`lambda-service-with-rds` with the pg <-> pg-pool cycle, on a pr that touched no rds file; its error hint names
`patches/pg-pool.patch`. the maintainer opens it, reads its header's `.recut` line (one context line on each side),
refreshes the hunk, and ships a release.

**kai, an adopter with an empty patch map (#7), re-locks before that release lands.** `pnpm install` exits 0 and
prints a warn that `patches/pg-pool.patch` failed to apply to pg-pool. kai misses it in the scroll. `npm run test`
runs `test:lint:cycles`, which exits 1 and names `pg/lib/index.js` <-> `pg-pool/index.js`. ci blocks the merge. kai
greps for pg-pool, opens `patches/pg-pool.patch`, and its header says: this patch drops pg-pool's lazy
`require('pg')`; if it no longer applies, upgrade declapract-typescript-ehmpathy and re-apply. kai does, and lint is
green.

**repos with keys of their own (#8, #9, #33).** a map with only `"other@1.0.0"` keeps it, and the path is kai's. a map
with its own `"pg-pool@3.14.0"` has that key retired as stale by the apply, then the path is kai's. priya holds both:
both effects, then kai's path.

**lee, whose code calls `new Pool()` from pg-pool directly (#16–#18, #36).** the patch did not apply, so pg-pool keeps
its fallback and lee's pool still connects. lint is red all the same, and lee's path to green is kai's.

fail-safe: loud at two gates (the install warn, the lint red), caught before merge, and the file each gate names
teaches the fix. the defect cannot ship green, whatever the repo's patch map or call style.

## bdd sketch

```
given('[case3] pg-pool at a release whose fallback line differs from the shipped hunk; an empty patch map')
  when('[t0] the maintainer ci runs the usecase walk')
    then('lambda-service-with-rds [t3] fails on a cycle through pg-pool, with a hint that names patches/pg-pool.patch')
  when('[t1] an adopter runs pnpm install')
    then('the install exits 0 and warns that patches/pg-pool.patch failed to apply')
  when('[t2] the adopter runs npm run test')
    then('test:lint:cycles exits 1 and names pg/lib/index.js <-> pg-pool/index.js')
    then('no path reports green with the cycle present')
  when('[t3] the adopter opens patches/pg-pool.patch')
    then('its header names the fix: upgrade declapract-typescript-ehmpathy, then re-apply')

given('[case3.other] the same release; the map holds only "other@1.0.0"')
  when('[t0] declapract apply, then pnpm install, then npm run test')
    then('"other@1.0.0" is untouched')
    then('the same warn, red lint, and teach as [case3]')

given('[case3.own] the same release; the map holds only "pg-pool@3.14.0", re-locked past it')
  when('[t0] declapract apply')
    then('stale-patched-dependency retires "pg-pool@3.14.0" and its file; the shipped key remains')
  when('[t1] pnpm install, then npm run test')
    then('the same warn, red lint, and teach as [case3]')

given('[case3.own+other] the same release; the map holds "pg-pool@3.14.0" and "other@1.0.0", re-locked past 3.14.0')
  when('[t0] declapract apply')
    then('stale-patched-dependency retires "pg-pool@3.14.0" and its file')
    then('"other@1.0.0" is untouched; "pg-pool": "patches/pg-pool.patch" remains')
  when('[t1] pnpm install, then npm run test')
    then('the same warn, red lint, and teach as [case3]')

given('[case3.direct] the same release; the repo calls new Pool() from pg-pool with no Client (any patch map)')
  when('[t0] pnpm install, then the pool connects')
    then('the connect succeeds, since the unpatched fallback stays')
  when('[t1] npm run test')
    then('test:lint:cycles exits 1, the same as [case3]')
```
