# 🌙 dream: retire `eslint-plugin-react-native` from the lint-react-native practice

- kind = fix
- owner = ehmpathy/declapract-typescript-ehmpathy
- caught 2026-10-16, on route `.behavior/v2026_09_29.fix-absorb-recent-upgrade-reports`

## .the cue that fired

the expo convergence fix retired `lint-react-native/best-practice/.eslintrc.js`: `lint` treats any
`.eslintrc.js` as a bad practice and strips every eslint dep, so the template was deleted on each
apply. what is left of `lint-react-native` is one CONTAINS floor: `eslint-plugin-react-native@4.0.0`.

## .the gap, precisely

- no expo adopter runs eslint (biome is the linter; `lint.bad-practice.eslint` removes `eslint`)
- so `eslint-plugin-react-native` is a dep that no tool loads, and `depcheck` may flag it as unused
- `lint-react-native` is then a practice whose only effect is that dead dep

## .the shape of the fix

1. add `eslint-plugin-react-native` to `depsBlocklist` in
   `src/practices/lint/bad-practices/eslint/package.json.declapract.ts`
2. delete `src/practices/lint-react-native/` and drop it from `src/useCases.yml` (`app-react-native-expo`)
   and `src/.test/assets/expo-fullusecase/declarations/useCases.yml`
3. update the two roster lists in `cicd-app-react-native-expo/.declapract.integration.test.ts`

## .why it is not done in this round

safe, but not clean: it removes a dep from every expo adopter's `package.json` and retires a
practice from a usecase roster — a change the wish's reports never raised, outside the convergence
fix that surfaced it.
