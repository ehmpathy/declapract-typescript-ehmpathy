- kind: reseed (a route of its own, in this repo)

## .the cue that fired
r11 i005 and r10 i005 of the #781–#811 absorb: prefixed globals, a named-arg parser per file, and `set -eu` that leaks into the parent shell; and a staged path with a newline halts the timestamp hook as "repair git".

## .the gap, precisely
- `husky/best-practice/.husky/pre-commit` sources each `check.*.sh`, so each hook shares the shell of every other line in `pre-commit`
- the hooks read `git diff --cached --name-only` by line; a path git quotes (a newline) cannot be read back

## .the shape of the fix
- `pre-commit` runs `sh "$(dirname -- "$0")/check.x.sh" || exit $?` per hook
- drop the `TIMESTAMPS_LOCK_HALT_*` style namespace workarounds
- read staged paths with `-z` where the hook runs as its own process
- clamp: an adopter line after the hooks still runs; a newline path is scanned

## .why it is not done in this round
it changes how an adopter's own `pre-commit` lines run, through an EQUALS-checked file: a behavior change no issue in the window asked for (F20)
