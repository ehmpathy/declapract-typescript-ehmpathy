# deliver: #597 — glob the stage segment in the shared-cache dynamodb IAM grant

## what shipped

`serverless/best-practice/serverless.yml` now grants the shared domain-driven cache table with the
stage segment **globbed**, replacing the earlier D27 two-line stage+access dual-grant:

```yaml
# before (the D27 two-line workaround)
- table/infrastructure-${self:provider.stage}-table-domain-driven-cache
- table/infrastructure-${self:custom.access}-table-domain-driven-cache

# after (#597)
- table/infrastructure-*-table-domain-driven-cache
```

## why the glob supersedes the two-line workaround

the two-line workaround was written under the D27 *theory* (code names the cache by access → grant
the access-keyed name). #597 is the **live, cloudwatch-confirmed truth**: the cache is one SHARED
dynamodb table addressed by a single canonical name (below prod that name is `-dev-`), regardless of
which fleet reads it. so:

- a dual-publish service runs two fleets whose roles key on different stages (ancient `stage=dev`,
  contemp `stage=prep`)
- both templated grants (`provider.stage` and `custom.access`) expand to `-prep-` for the contemp
  fleet, while the code reads the shared `-dev-` cache
- ⇒ the contemp `-prep-` fleet AccessDenies on `infrastructure-dev-...`, and a with-simple-cache
  read-back throws a 500 instead of a null (a 400 → 500)

the glob covers `-dev-`, `-prep-`, and `-prod-` in one line. still least-privilege: account-scoped
(`${aws:accountId}`) and name-scoped to the one cache family — it widens only across stage, the axis
the fleets differ on. an enumerated `dev`+`prep` list would have dropped `-prod-`.

## provenance

found live in `svc-gateway` `prep / assure`: 3 chat endpoints 500'd on the contemp `-prep-` fleet
only (ancient passed); cloudwatch named the AccessDeny on
`infrastructure-dev-table-domain-driven-cache`. same class as #596 (deploymentBucket account-scope)
and #577 — a resource addressed by one axis while a grant templates it on another; the IAM facet of
the ancient→contemp dual-publish.

break; the glue question is left for its own evidence.
