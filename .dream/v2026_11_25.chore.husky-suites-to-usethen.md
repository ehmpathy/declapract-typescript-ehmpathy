# 🌙 dream: the husky play suites share each guard run via useThen, with fixtures in given

- kind: chore
- owner: declapract-typescript-ehmpathy, the husky practice
- caught 2026-11-25

## .the cue that fired
a verification peer review of the timestamp-hook pr flagged the suite's `const result = runGuard(...)`
in each `when` as a `useThen` miss, and its fixture builds in `when` as setup outside `given`.

## .the gap, precisely
`check.timestamps.play…` and `check.secrets.play…` build a temp repo and spawn the guard at jest
collection time, in `when`, and share the result by a `const`. the repo's dominant shape (115 `useThen`
uses, among them the peer `check.timestamps.lock.play…`) defers the work to test time and names it.
also: `[case1]`, `[case15]`–`[case17]` bundle several asserts per `then`; `[case17]` sits after
`[case22]`; `[case-scope]` breaks the `[caseN]` label form.

## .the shape of the fix
one pr, both suites: `const result = useThen('the guard runs', async () => runGuard({ dir: genStagedRepo(...) }))`
per `when`, fixtures built inside that call; split each bundled `then`; renumber `[case-scope]`,
reorder `[case17]` with its no-exemption asserts kept byte for byte. rows and snapshots unchanged,
so a green run proves no intent moved.

## .why it is not done in this round
it rewrites 17 cases the timestamp pr did not write, one of them the guard's own no-exemption proof;
a rewrite that wide belongs in its own pr, where a reviewer reads it as a refactor alone. fulcrum F6.
