# case=3 — commit hooks fail closed, and name who fixes it (e4)

## .narrative
a clone in sdk-aws-lambda commits through the practice's hooks a dozen times a day. on 0.50.0 each hook could wave a fault through, and the clone would never know:
- a git hiccup in the lock's `hash-object` told it "check.timestamps.sh was changed", with a fix that rewrote a hook it never touched
- a `git rm --cached .husky/check.timestamps.sh` dropped the hook from the commit, and the lock let it pass
- a grep fault inside the secrets scan read as "no key found", and the commit went through
- an anthropic key it pasted by mistake was named "openai-style", so it rotated the wrong key first
- a broken yalc read as "no references"; a found reference printed a line and still committed
- a yalc link it cleaned from package.json on disk, but never re-staged, still committed
- a file it moved and then edited to hold a key or a clock staged as a rename, so the scans never read its new lines
- on a fresh clone, the lockfile reminder's `git diff HEAD@{1}` failed silently, so it never learned to reinstall

after the upgrade, the clone meets three answers and only three. clean: the commit passes, silent. caught: `✋ ConstraintError`, exit 2, the file and line (never the key), and the fix. blind: `💥 MalfunctionError`, exit 1, the fault named, and the commit does not pass. the clone always knows whether to fix its change or its machine.

the words it meets are reviewed before they ship: a harness stages each case in a temp repo, runs secrets and timestamps under `bash`, sources yalc, the lockfile reminder, and the lock from `sh`, and snaps every refusal. one case ([case9] of the secrets harness) runs the whole pre-commit chain as husky does, sourced by `sh`, in a checkout that never ran `husky install`.

## .timeline
```
given('a clone that commits in a repo with the upgraded hooks')
  when('[t0] it stages an sk-ant- key')
    then('exit 2; shape: anthropic key; the line number, never the key')
  when('[t1] it stages a file with a utc clock stamp')
    then('exit 2; the file and line named')
  when('[t2] it removes check.timestamps.sh from the index, kept on disk')
    then('exit 2; found: absent (in the index)')
  when('[t3] git hash-object fails under it')
    then('exit 1; MalfunctionError; never "was changed"')
  when('[t4] grep faults inside a scan')
    then('exit 1; MalfunctionError; the commit does not pass')
  when('[t5] its package.json holds a yalc reference')
    then('exit 2; ConstraintError; fix: npx yalc remove --all')
  when('[t6] yalc is absent')
    then('exit 0; no stdout notice')
  when('[t7] it pulls on a fresh clone with no reflog')
    then('no crash; the install reminder still fires, with the reason named, for pnpm-lock.yaml or package-lock.json')
  when('[t8] it cleans a yalc link from package.json on disk, but the staged copy still holds it')
    then('exit 2; found: the staged spec; fix: npx yalc remove --all && git add package.json')
  when('[t9] it moves a file, edits it to hold a key or a clock, and stages the rename')
    then('exit 2; the new path and line named; the moved lines are scanned, never skipped as a rename')
  when('[t10] it commits in a checkout that never ran husky install, with a message commitlint rejects')
    then('commit-msg still lints, never skips silent; exit 1; the commit does not land')
```
