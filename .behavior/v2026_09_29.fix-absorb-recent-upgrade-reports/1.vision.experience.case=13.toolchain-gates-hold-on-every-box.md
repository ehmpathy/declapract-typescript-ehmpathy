# case=13 — the format and lint gates hold on every box

critipath · feel: happy · cells: A=adopter × B1/B5 × C1/C2/C3 × D1, A=system × B5 · issues: #645, #601, #616, #628, #600, #516

## .narrative

before: `test:format` chained `terraform fmt`, so it failed on any laptop without a terraform
binary, and said so nowhere. `test:lint:cycles` read `.dpdmrc.yaml` through `yq`, a host binary no
practice declares, and its `// "^$"` fallback was dead syntax. the `.dpdmrc.yaml` policy allowed a
devDep entry, but the file was EQUALS, so every apply deleted the entry the policy allowed. and the
terraform pin (0.14.11) could not satisfy the `>= 1.7` that the same practice set required.

after: the formatter set is biome only; apply removes the `terraform fmt` commands from an adopter's
`package.json`, and ci no longer installs terraform for the format job. `test:lint:cycles` reads
`.dpdmrc.yaml` with node and the `yaml` devDependency, and fails closed if it cannot. the
`.dpdmrc.yaml` check accepts any `exclude` list without `node_modules`, so an adopter's cited entry
survives. the terraform pin satisfies every `required_version` the practices declare.

the commit lint had the same shape of gap (#516). the body rule warns at 140, but no footer rule
followed it, so config-conventional's error at 100 still applied — and a squash body's tail lands
in the footer. now the footer rule warns at 140 beside the body rule.

## .[tn] sketch

```
given('[case1] a laptop with no terraform and no yq, on a repo one release behind')
  when('[t0] declapract apply')
    then('package.json holds no fix:format:terraform or test:format:terraform, and test:format runs biome only')
    then('yaml is a devDependency, and test:lint:cycles holds no yq')
  when('[t1] npm run test:format and npm run test:lint')
    then('green, with no host binary beyond node')
  when('[t2] declapract apply again')
    then('zero files change')

given('[case2] a .dpdmrc.yaml with a cited devDep exclude entry')
  when('[t0] declapract apply')
    then('the entry survives')
  when('[t1] the entry is node_modules')
    then('the check is red')

given('[case3] this repo\'s tests')
  when('[t0] the version clamp runs')
    then('.terraform-version satisfies every best-practice required_version')

given('[case4] the ci test workflow')
  when('[t0] the format job runs')
    then('no terraform setup step runs')

given('[case5] a squash-merge commit whose body tail holds a 120-char line (#516)')
  when('[t0] commitlint runs on it')
    then('a warn, never an error; the pr check stays green')
  when('[t1] a header over 140 chars')
    then('a warn, as before')
```
