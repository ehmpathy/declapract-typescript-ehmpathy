# case=9 — a test run never guesses which credentials it holds

critipath · feel: sharp where it used to be silent · cells: A=adopter × B3/B7 × C1 × D1, A=system × B3 · issues: #611, #612, #651, #623, #675

## .narrative

before: on a dev box with no `AWS_PROFILE`, an integration run that needed aws fell through the sdk's
credential chain to the box's ec2 instance role. it passed, against resources the test never meant to
touch. a cloud acceptance run aimed at prep from a laptop sourced the **test** keyrack, since jest
defaulted access to `test`, and hung. every suite file sourced keyrack again, ~25s each.

after: when the repo declares aws auth, useKeyrack bars the metadata service
(`AWS_EC2_METADATA_DISABLED=true`) and sources keyrack strict, so an absent credential fails loud
with the unlock command; the instance role can no longer stand in silently. a cloud acceptance run
with no `ACCESS` and no `LOCALLY=true` stops at once and says to set `ACCESS=prep|prod`. keyrack is
sourced once per run, in globalSetup, after the livedb wake and before autoprune.

the config a run reads matches the access it holds. before, `ACCESS=prep` under jest's
`NODE_ENV=test` still resolved config `test`, so a prep request built from config (a twilio
signature) failed. the acceptance env file now sets `CONFIG` to the same value as `ACCESS`, before
any test imports the environment.

## .[tn] sketch

```
given('[case1] a repo that declares an aws account, on a box with an instance role and no AWS_PROFILE')
  when('[t0] npm run test:integration with keyrack locked')
    then('red, with the keyrack unlock command in the error')
    then('no aws call succeeds via the instance role')
  when('[t1] keyrack unlocked, npm run test:integration')
    then('green, and keyrack is sourced once for the run, not once per suite file')

given('[case2] a laptop run of the cloud acceptance suite')
  when('[t0] npm run test:acceptance with no ACCESS and no LOCALLY')
    then('red at once, with "set ACCESS=prep|prod for a cloud acceptance run"')
  when('[t1] ACCESS=prep npm run test:acceptance')
    then('the prep keyrack is sourced, and the run reaches prep')
    then('getConfig() resolves the prep config, not test (#675)')

given('[case3] an unattended ci runner')
  when('[t0] the test jobs run')
    then('keyrack and the metadata bar are skipped, as before (CI short-circuits)')
```

## .the aha

a test that passes on the wrong credentials is worse than a test that fails.
