# 🌙 dream: `git.repo.test --resnap` with a name scope deletes the snapshots of every skipped suite

- kind: reseed (another repo)
- owner: ehmpathy/rhachet-roles-ehmpathy (role=mechanic, skill=git.repo.test)
- caught 2026-11-19

## .the cue that fired
the #781–#811 absorb: `rhx git.repo.test --what integration --mode apply --scope 'name://<a describe>' --resnap` ran 29 tests, skipped 1774, and deleted 94 tracked snapshot files as obsolete.

## .the gap, precisely
- a `name://` scope maps to jest's `--testNamePattern` across every file; with `--resnap` (`-u`), jest treats each snapshot of a skipped test as obsolete and removes it, and a file whose every test was skipped loses its whole `.snap`
- the skill's output reports `0 failed` and says naught of the removals

## .the shape of the fix
- refuse `--resnap` with a `name://` scope alone (exit 2), and name the fix: add a `path://` scope to the same files
- or pass `--ci=false -u` only to the files the path scope matched
- after any `--resnap`, list each snapshot file removed, so a removal is never silent
- clamp: a fixture repo with two suites, a name-scoped resnap of one, assert the other's `.snap` survives

## .why it is not done in this round
the skill lives in rhachet-roles-ehmpathy; here it was repaired by a full unscoped resnap after the last full run proved every snapshot current
