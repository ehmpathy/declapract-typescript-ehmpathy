# case=5 · expo adopter takes the same upgrade

feel: happy · care: critipath

## .narrative

an `app-react-native-expo` repo takes the same `declapract upgrade` as case=3. the typescript floor never moves for it: the ts7 floor lives in typescript-node, which the expo usecase does not take. `expo install --check` stays clean, since expo sdk 56–58 expects `typescript ~6.0.3`. the maintainer notices naught. that is the point: the practice never puts an expo repo in a state its sdk rejects.

once an expo sdk expects typescript 7, a follow-up raises the floor in typescript-expo. that is caught as a dream, not built here.

## .timeline

```
given('an app-react-native-expo repo on its expo sdk typescript range')
  when('[t0] the maintainer runs `declapract plan` after the ts7 practice ships')
    then('no change to the typescript dep is proposed')
  when('[t1] the maintainer runs `CI=1 npx expo install --check`')
    then('it exits 0; typescript is not listed as outdated')
```
