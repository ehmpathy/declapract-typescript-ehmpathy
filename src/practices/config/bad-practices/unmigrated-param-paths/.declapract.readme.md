a config that names a param by an explicit path — `$.at(aws::param/org/repo/…)` — cannot be flipped
to the bare `$.at(aws::param)` by a fix: the bare form makes sdk-config read
`/{org}/{project}/{config}/{keyPath}`, a param that holds no value until someone copies it there.
a flip before the copy breaks `getConfig()`.

so the fix leaves every path as is and stamps a top-level `"@declapract:review"` key into each of
`config/{test,prep,prod}.json` (all three, so their key sets stay equal) that names the copy step.
zod's object schema strips the key on parse.

to migrate:

1. copy each explicit-path value to its derived name (see `provision/aws/readme.md` in the
   `persist-with-rds` practice)
2. swap each explicit path for the bare `$.at(aws::param)`
3. delete the `"@declapract:review"` key; with no explicit path left, the check no longer flags it
