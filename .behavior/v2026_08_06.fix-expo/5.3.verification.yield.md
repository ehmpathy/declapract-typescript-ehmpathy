### a gap found AND fixed this gate — depcheck lint
- **found:** `rhx git.repo.test --what lint` failed. `depcheck` walked the greenfield fixture's
  per-practice symlink mirror `test/assets/expo-fullusecase/declarations/practices/lint` →
  `src/practices/lint`, reached `lint/bad-practices/eslint/.eslintrc.js`, and flagged its eslint
  plugins as missing deps. that eslintrc is a forbidden-pattern template declapract ships, already
  ignored at its canonical `src/` path — the symlink reached it via a path the glob did not span.
- **cause, not symptom:** the `lint` symlink is required — `[case2]` proves the FULL 23-practice
  usecase runs, so every referenced practice must be found. the fixture is correct; the ignore glob
  was too narrow.
- **fix:** generalized the `.depcheckrc.yml` ignore from `src/practices/lint/bad-practices/*` to
  `**/practices/lint/bad-practices/*`, so it spans the canonical path AND any test-asset symlink
  mirror. re-ran lint → **passed (4s)**.
