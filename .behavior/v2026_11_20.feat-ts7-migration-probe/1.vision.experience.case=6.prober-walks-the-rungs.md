# case=6 · the prober walks the rungs · the dense walk

feel: sharp · care: critipath · boundaries: 6

the densest walk: one prober, one repo, every seam the probe must cross before it may claim a verdict. the sharp moments inside it (cache trap, removed options, alias rewrite) each fail safe here and have a spotlight elsewhere (`case=4`, `case=7`).

## .narrative

the prober starts on this repo at `typescript 5.4.5`. the first timed run reads fast, too fast. `incremental: true` left a `tsconfig.tsbuildinfo`, and the "cold" read was warm. the protocol already guards this: each run deletes the buildinfo and passes `--incremental false`, so the warm-up run is the only warm one and is discarded.

next, the tsconfig migration: `baseUrl` out, `./` prefixes on `paths`, `importsNotUsedAsValues` out, `types` declared. the 5.4.5 rung reruns on the migrated tsconfig and stays clean. that row proves a half-upgraded adopter stays green.

the 6.0.3 rung prints its deprecations, each with a code. the prober copies each into the break list, and each names a fix already in the migrated tsconfig. any row without a fix is a candidate wall.

the 7.0.2 rung runs twice, once default and once `--singleThreaded`. wall drops sharply; cpu may rise in the default run as checkers fan out. the single-thread row shows the native gain alone.

each median sits beside its min–max spread. if two rungs' spreads overlap, the table says "within noise" rather than print a ratio. a ratio that a noisy run could flip is no measured answer.

this repo builds via `declapract compile`, not `tsc`, so it has no emit to check. the prober moves to the consumer repo `rhx declapract.walk --usecase lambda-service` lays down in a temp dir, from the practice's own templates. there, the emit check: build `dist/` once under 5.4.5 and once under 7.0.2, then diff the two trees. each emitted-js difference joins the list as a behavior change, marked runtime-relevant or cosmetic (whitespace, helper order).

then the build seam: `tsc -p ./tsconfig.build.json && tsc-alias -p ./tsconfig.build.json` under 7.0.2. the prober greps `dist/**/*.js` for `@src/`. zero hits means the seam holds. a hit makes the verdict `fails`, with the grep output as evidence (`case=2`).

last, `rhx declapract.walk --usecase lambda-service` proves the practice change converges: a second `plan` shows no automatic fix. the prober checks the F5 bar and writes the verdict.

## .timeline

given('this repo on typescript 5.4.5 with incremental: true')
  when('[t0] the prober times `tsc --noEmit` with a buildinfo left over')
    then('the protocol deletes tsconfig.tsbuildinfo and passes --incremental false each run')
    then('the warm-up run is discarded; five cold runs follow')
  when('[t1] the prober migrates the tsconfig and reruns the 5.4.5 rung')
    then('it exits 0; the migrated tsconfig is valid on 5.4.5')
  when('[t2] the prober runs the 6.0.3 rung')
    then('each deprecation is listed by code; each maps to a fix in the migrated tsconfig')
  when('[t3] the prober runs the 7.0.2 rung, default and --singleThreaded')
    then('it exits 0; median wall, cpu, peak rss recorded per rung')
    then('each median carries its min–max spread')
    then('rungs whose wall spreads overlap read "within noise", never a ratio')
  when('[t3.1] in the walked lambda-service consumer, the prober diffs dist/ built by 5.4.5 against dist/ built by 7.0.2')
    then('each emitted-js difference is listed as a behavior change, runtime-relevant or cosmetic')
  when('[t4] in the same consumer, the prober builds under 7.0.2 and greps dist for @src/')
    then('zero hits → the alias seam holds')
    then('any hit → verdict fails; the grep output is the evidence')
  when('[t5] the prober runs `rhx declapract.walk --usecase lambda-service`')
    then('the final plan holds no automatic fix (converged)')
  when('[t6] the prober checks the holds bar (F5)')
    then('every break has a shipped fix valid on 5.4.5, ci green, wall not slower → holds')
    then('else → fails, with the unmet clause named')
