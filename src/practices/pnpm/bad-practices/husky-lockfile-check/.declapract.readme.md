# bad-practice: husky-lockfile-check

## .what

a husky hook (`.husky/check.lockfile.sh`) that watches the npm `package-lock.json` for
changes and points the human at `npm install`.

## .why it is bad under pnpm

a pnpm repo has no `package-lock.json` — its lockfile is `pnpm-lock.yaml`. a hook left on
the npm name never fires on a real pnpm lockfile change, so the stale-dependencies
reminder silently dies.

## .the fix

swap `package-lock.json` → `pnpm-lock.yaml` and `npm install` → `pnpm install`. idempotent
— once swapped, the check no longer detects the npm name.
