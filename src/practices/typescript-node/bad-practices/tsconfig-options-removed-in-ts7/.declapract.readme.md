a tsconfig that sets `baseUrl` or `importsNotUsedAsValues`; typescript 7 removed both (TS5102, TS5023).

the fix removes both, at any value, and the `paths` that `baseUrl` anchored. the best-practice tsconfig then lays down the template's one alias, `@src/*`.

the break: an import that leaned on the old shape (a bare `'logic/x'` under `baseUrl`, a repo's own alias) fails loud with TS2307 on the next typecheck. move it to `@src/`.
