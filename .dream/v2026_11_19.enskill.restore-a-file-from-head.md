## .the cue that fired
seven files restored to HEAD in one round after a self-apply overshot; `git checkout -- <file>` and `git restore` are not paved.

## .the gap, precisely
- the only paved path is `git show HEAD:<file> | rhx teesafe <file>`
- teesafe drops the final newline, so each restore leaves a one-line diff that needs an Edit
- `| tail -0` after teesafe closes the pipe early and truncates the file

## .the shape of the fix
- `rhx git.file.restore --path <file> [--ref HEAD]`: plan by default, apply writes the exact blob bytes (via `git cat-file -p`), refuses a path outside the repo, reports `restored | unchanged`
- separately: teesafe should keep the final newline its stdin carries
