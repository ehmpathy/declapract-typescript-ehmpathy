# case=7 — one upgrade, end to end (e1 · e4 · e24 · e2 · e21 · e27 · e3 · e7; the densest walk)

## .narrative
a clone on a shared grove upgrades svc-notifications to this release. one walk crosses every boundary the queue reported.

it runs `declapract apply`. the local `test:unit` walks `src/` and `.agent/repo=.this/`, and skips the rmsafe trash and the actor plugin dir. `test:lint` finishes in seconds. it commits; the hooks verify the lock, scan for clocks and keys, and pass. one hook would have halted with the owner named had git faulted; none did.

it pushes. one acceptance suite fails on a real regression the upgrade exposed. the reviewer opens the pr and sees `test-passed` red. its summary names the one suite job that failed (`suite / test-acceptance-locally: failure`), so the reviewer clicks once, straight to the cause. the clone fixes the suite and pushes; every check goes green, `test-passed` goes green, and the pr is mergeable under the old protection.

on merge, `github / plan` and `github / apply` both run in `production-on-main`, and the apply lands on the first run. protection now requires `test-passed` and `pullreq-title`. the clone reads #806 and #807 closed by this release, and moves on.

## .timeline
