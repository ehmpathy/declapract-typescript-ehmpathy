wish =

## .what

pull into `ehmpathy/declapract-typescript-ehmpathy` the practice defects that recent declapract
upgrades reported back — svc-chat, svc-notifications, svc-quotes, whodis-client, and peers,
each of which filed what the practices got wrong as it went through them.

the reports are the open issues filed 2026-09-24 onward, `#622` through `#652`:

```
gh issue list --repo ehmpathy/declapract-typescript-ehmpathy --state open --search 'created:>=2026-09-24'
```

## .the outcome

- every report in that window is triaged: fixed in this tree, or left open with a one-line
  reason on the issue (too large, needs a human decision, or belongs with another report)
- the fixes that land are the ones a NEXT upgrade would otherwise trip on again — a practice that
  ships code that does not compile, a check that can never pass, a fixer that breaks the build,
  an apply that does not converge
- each fix names the issue it closes, so the reporter's repo can see its report landed
- no fix narrows or silently drops a practice a service relies on

## .why now

every service that goes through the upgrade next — svc-quotes is mid-route right now — meets the
same defects its predecessors already reported. each one fixed here is fixed for every repo after.
