# case=4 — a shard of skipped suites reports green (e5)

## .narrative
a clone in bhuild pushes a branch. its `explicit` acceptance shard holds one credential-gated suite, which skips in ci. on 0.50.0 the clone watches that shard turn red on its last step, the slow-test report: "parsed 0 durations… schema likely changed". every test passed or skipped; naught in its own repo is wrong. the script is the practice's, so the clone cannot fix it without drift, and it reruns, red again.

after the upgrade, the clone pushes the same branch. the shard runs its one suite, which skips. the report counts only files that ran at least one test (a nonzero count of passed or failed tests), finds none, writes "none ran a test (each was skipped, or failed before its first test)" to the step summary, beside the count of files it read, and passes. the clone reads the summary and knows why the table is empty.

a week later, a jest bump really does move the duration fields. the clone's unit shard ran 140 tests and yields zero real spans; the report still fails loud with the schema-drift error, and names where to look. the guard the check exists for still bites.

## .timeline
```
given('a clone whose pr runs ci on the upgraded practice')
  when('[t0] a shard where every suite skipped finishes (0 passed, 0 failed, each span 0)')
    then('the slow-test report exits 0')
    then('the step summary says none ran a test, each skipped or failed before its first test')
  when('[t1] a shard that ran tests finishes, and each span reads 0')
    then('the report exits 1 with the schema-drift error, as today')
  when('[t2] a shard that ran tests finishes with real spans')
    then('the report exits 0 with the ranked table, as today')
  when('[t3] a shard with no test files finishes')
    then('the report exits 0, empty shard, as today')
```
