# case=6 — the transaction wrapper types for every caller

critipath (if it reproduces) · feel: happy · cells: A=adopter × B1 × C1 × D1, A=maintainer × B1, A=system × B1 · issue: #627

## .narrative

svc-chat's upgrade re-emitted `withDatabaseTransaction.ts` byte-for-byte, and `tsc` then failed
inside the practice's own file: the declared `Promise<Awaited<R>>` was not reachable from its body.
the agent could patch it locally, but the next `apply` would re-emit the template and undo the patch.

this tree's body differs from the one the issue quotes (the issue's body spreads a fresh context
into `logic`; this tree passes `context` through), and the file carries a `.note` that defends the
wrap. so the round does not argue it. a fixture holds both bodies and three callers — an async op,
a sync op, and a generic op — and `tsc` under the practice's own strictest config is the verdict.

- it reproduces → the return becomes `Promise<R>`, the `.note` is rewritten to match, and the
  fixture is the clamp that keeps it.
- it does not → the issue closes as refuted, with the fixture and its green `tsc` as the proof, and
  the fixture still lands as the clamp, so a later edit of the wrapper cannot reintroduce it.

either way, the next adopter's `tsc` passes on the bytes the practice emits.

## .[tn] sketch

```
given('[case1] an agent in svc-chat mid-upgrade, with an async op, a sync op, and a generic op wrapped in withDatabaseTransaction')
  when('[t0] the agent runs declapract apply, then tsc --noEmit')
    then('the agent sees no error that points into src/utils/database/withDatabaseTransaction.ts')
    then('the agent's sync op wrapper types as a Promise of its return, with no local patch')
  when('[t1] the agent runs declapract apply again')
    then('the template is untouched, so no patch was ever needed to survive it')

given('[case2] a maintainer who edits the wrapper's return type')
  when('[t0] the maintainer runs this repo's tests')
    then('the fixture — the practice body and the body the issue quotes, over the three callers — goes red if any caller fails tsc')

given('[case3] the unattended ci runner on the adopter's next pr (actor = system)')
  when('[t0] the types job runs tsc over the emitted bytes')
    then('green, with no error in the practice-owned wrapper')
```
