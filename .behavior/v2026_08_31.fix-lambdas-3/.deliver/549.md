## the defect — the emitted deploy.database.sh template carries gerunds

`persist-with-rds/best-practice/provision/schema/deploy.database.sh` is emitted verbatim to every
consumer. its progress-strings, one comment, and one error used `-ing` gerund forms, which trip the
mechanic gerund hook (`rule.forbid.gerunds`) on the emitted file downstream — so each repo re-fixes
it locally and re-diverges from the template.

## the fix — imperative/plain verbs, per the ticket's table (7 edits)

| line | was | now |
|---|---|---|
| progress | `🔨 creating the database...` | `🔨 create the database...` |
| progress | `🔨 installing the extensions...` | `🔨 install the extensions...` |
| progress | `🔨 creating the schema...` | `🔨 create the schema...` |
| progress | `🔨 granting reads to the datalakedb user...` | `🔨 grant reads to the datalakedb user...` |
| progress | `🔨 creating the cicd user...` | `🔨 create the cicd user...` |

| error | `...with terraform before running this` | `...with terraform before you run this` |

no behavior change — the emitted procedure runs identically; only the human-readable strings change.
