# 🌙 dream: git.repo.test matches the `._.{acpt,intg,unit,eval}` test suffixes

kind: reseed · owner: ehmpathy/rhachet-roles-ehmpathy · caught 2026-10-12

## .the cue that fired

#679: declapract-typescript-ehmpathy's jest configs match both the old suffixes and the new
`$prefix._.{acpt,intg,unit,eval}.test.ts` form, and a bad-practice renames adopter files to it (F54).

## .the gap, precisely

`rhx git.repo.test` keys `--what` and its `--scope path://` filters on the old suffixes and on
`jest.*.config.ts`. after a rename, `--what unit` previews and scopes the wrong file set.

## .the shape of the fix

teach the skill the new suffix per kind (`acpt` ↔ acceptance, `intg` ↔ integration, `unit`,
`eval` ↔ evaluation), while it still matches the old form; a test over a repo with both forms.

## .why it is not done in this round

it is another repo's work (seed S5). the jest configs in this repo match both forms meanwhile, so no
test drops out of a run.
