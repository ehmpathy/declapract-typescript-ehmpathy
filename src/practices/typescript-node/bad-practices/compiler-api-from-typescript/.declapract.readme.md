a source file that reads the compiler api from the `typescript` package.

the typescript-node floor is typescript 7.0.2, whose `typescript` package exports only
`{ version, versionMajorMinor }`. an `import ts from 'typescript'`, a `require('typescript')`, or a
type import from it then fails to typecheck, or throws at runtime.

the classic compiler api ships on as `@typescript/typescript6`. to fix, by hand:

1. add the compat package to the repo's runtime deps: `pnpm add @typescript/typescript6@6.0.2`
2. swap each specifier: `from 'typescript'` → `from '@typescript/typescript6'`

no automatic fix is declared: step 1 edits `package.json`, which a check on a src file cannot reach,
and a swap without it would break the build. the check reads each file with the parser, so a
mention of `'typescript'` in a comment or a string is never flagged.

scope: the check reads `src/**/*.ts`. a load from a root file, a `.mts`, or a `.js` file is not
flagged here; it still fails loud on its own, at typecheck (TS2339 on the absent api) or at run
(`ts.createProgram is not a function`). the same two steps fix it.
