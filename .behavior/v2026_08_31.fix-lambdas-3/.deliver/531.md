## the defect — the test templates scope against a stale local `main`

`tests-any/best-practice/package.json` shipped `test:unit` and `test:integration` with
`--changedSince=main`. a local `main` drifts behind the real trunk the moment a teammate merges
without a local pull — so a consumer's changed-file test scope silently pulls in unrelated,
already-merged suites (slower, noisier, and a source of cross-branch failures that mislead). `origin/main`
is the true fork point; scope holds only this branch's own change.

## the fix — `main` → `origin/main` in both commands

edited the two shipped commands in `tests-any/best-practice/package.json`:
- `test:unit`: `--changedSince=main` → `--changedSince=origin/main`
- `test:integration`: `--changedSince=main` → `--changedSince=origin/main`

the `--acceptance` command carries no `--changedSince` (it runs the whole suite), so it is untouched.

### realigned the extant shell-flags clamp

`tests-any/package.json.shell-flags.declapract.integration.test.ts` hardcodes a COPY of the
`test:unit` command to prove the RESNAP/CI/THOROUGH shell-flag behavior. that copy + its THOROUGH
assertions still read the old `--changedSince=main`, so a template-only fix would leave the copy
stale (a latent drift). realigned the hardcoded command + the THOROUGH descriptions/assertions to
`--changedSince=origin/main` — the shell-flag BEHAVIOR under test is unchanged; only the incidental
branch token tracks the template. GREEN this pass (12 passed).

## the clamp — drift-proof, teeth dogfooded

added `tests-any/changedsince-origin-main.declapract.test.ts` (practice-root, never emitted): it reads
the REAL shipped `best-practice/package.json` (a single static-file read, as the kin
`dpdmrc-exclude-policy` / `commitlint-body-max-line` clamps do — so it CANNOT drift from a copy) and
asserts both commands hold `--changedSince=origin/main` and neither holds the bare `--changedSince=main'`
token (the trailing quote disambiguates: the origin form emits `--changedSince=origin/main'`, which
does not contain the bare-main token).

teeth confirmed this pass: reverted the template to `--changedSince=main` → all 3 assertions RED;
restored → 3 GREEN.
