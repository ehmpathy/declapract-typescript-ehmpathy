## the defect — a contradiction no repo state can satisfy, and a fix that walks you into it

the `domain` best-practice required `src/domain/objects/index.ts`, while its kin
`directory-structure-src/bad-practices/domain-dir` FORBIDS every file under `src/**/domain/**` and
ships a rename `fix` that relocates them to `src/domain.objects/`. both ship in `typescript-project`,
so a repo that satisfied `domain` violated `domain-dir`, and `domain-dir`'s fix moved the required
file AWAY — a terminal, unrepairable state (the `domain` half is companion-only, no template to
re-write it). the bad-practice half (`schematic-joi-model`) sat at the same deprecated `src/domain/`
path, so it was INERT on any migrated repo — a joi-model detector that could no longer reach what it
detects.

## what landed

### ask 1 — the best-practice move (landed by the 5.1 execution stone, verified here)

the go-forward layout is staged in-tree:
- `+ best-practice/src/domain.objects/index.ts.declapract.ts` (the go-forward path)
- `- best-practice/src/domain/objects/index.ts.declapract.ts` (the deprecated path)
- `+ .declapract.integration.test.ts` (the D51 clamp)

keyed on `domain.objects`, the two practices now AGREE: `domain-dir`'s fix produces exactly the path
`domain` requires. verified this pass — the clamp runs GREEN (see below).

### ask 2 — the joi-detector glob move (landed this pass)

relocated the `schematic-joi-model` subject glob from the inert deprecated path to the go-forward one:
- `+ bad-practices/schematic-joi-model/src/domain.objects/**/*.ts.declapract.ts`
- `- bad-practices/schematic-joi-model/src/domain/**/*.ts.declapract.ts`

the declaration is byte-identical (a pure content detector — `includes('SchematicJoiModel')` → rewrite
to `domain-objects`); only its subject glob moved. it now reaches joi models where a migrated (or
freshly-scaffolded) repo actually holds them. a legacy repo still at `src/domain/` is caught on the
next pass once `domain-dir` relocates it — the same two-pass settle declapract already supports.

## the clamp — extended, teeth dogfood-verified

extended the D51 integration clamp (`domain/.declapract.integration.test.ts`, practice-root, never
emitted) with `[case2]`: it walks the `schematic-joi-model` tree, strips `.declapract.ts` to the

this reuses the exact `isUnderBareDomainSegment` predicate `[case1]` already proves, extended to the
bad-practice half the original clamp did not walk.
