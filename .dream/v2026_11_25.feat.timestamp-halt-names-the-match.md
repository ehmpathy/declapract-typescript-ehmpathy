kind: feat · owner: declapract-typescript-ehmpathy · caught 2026-11-25

## .the cue that fired
peer review of the check.timestamps fix: a dev halted on a verse ref or a scale ratio (`n:nn`) sees the
whole line, not the part that tripped the hook, and a file with five clocks costs five commits.

## .the gap, precisely
the halt prints `file:line:<line>` for the first hit only (`head -n 1`). no snapshot shows the
halt output for any form but the iso stamp in `[case1]`.

## .the shape of the fix
print each hit line with the matched part marked (`grep -o` per hit, or loop the named forms and
name the one that fired), add a `fix: mask it as [time]` line, and snapshot one halt per form
family with the clock masked in the `.snap`. the same pass owes the two fault headers a fix line
(blob read: `git status`, then retry; broken pattern: revert the hook edit, run the suite), and the
sed fault its exit code beside the grep fault's `(grep exit 2)`.

## .why it is not done in this round
the vision keeps the halt message unchanged; a new message reaches every consumer and owes its own
review.
