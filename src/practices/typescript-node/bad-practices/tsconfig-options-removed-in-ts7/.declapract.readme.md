a tsconfig that sets `baseUrl` or `importsNotUsedAsValues`; typescript 7 removed both (TS5102, TS5023).

the fix removes both, at any value, and the `paths` that `baseUrl` anchored. the best-practice tsconfig then lays down the template's one alias, `@/*`, anchored at the repo root.

the break: an import that leaned on the old shape (a repo's own alias under `baseUrl`) fails loud with TS2307 on the next typecheck. name the module through `@/` instead (`@/src/domain.operations/x`).
