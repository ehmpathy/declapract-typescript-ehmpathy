# case=2: an adopter whose repo already holds patch keys

covers inventory #2 (other only), #3 (own only), #31 (own+other).

proof: `pg-pool-patch.declapract.integration.test.ts` `[case4]` proves the apply keeps every key, and that pnpm
applies the exact key first and leaves no `require('pg')` in pg-pool. the "cycle check exits 0" steps below follow
from that content: `[case6]` proves a pg-pool with no `require('pg')` passes the shipped check. no test runs
`test:lint:cycles` on these exact trees.

## narrative

priya owns svc-service-providers. last sprint she hand-wrote `pnpm.patchedDependencies["pg-pool@3.14.0"]` to get
lint green, beside an older `"other@1.0.0"` key for an unrelated fix (#31). she bumps declapract-typescript-ehmpathy
and runs `npx declapract apply`. she checks the diff: her two keys are still there, and a third, `"pg-pool":
"patches/pg-pool.patch"`, sits beside them. she runs `pnpm install` and `npm run test:lint:cycles`; both pass. a month
later pg-pool ships 3.14.1. she re-locks and applies again: the diff now deletes her `pg-pool@3.14.0` key and its file,
and keeps the shipped one and `"other@1.0.0"`. lint stays green.

her two teammates see the halves of her path: one repo holds only `"other@1.0.0"` (#2), and its key survives the
apply; another holds only `"pg-pool@3.14.0"` (#3), which pnpm applies first until the re-lock retires it.

## bdd sketch

```
given('[case2.other] an rds repo whose map holds only "other@1.0.0"')
  when('[t0] declapract apply, then pnpm install, then npm run test:lint:cycles')
    then('"pg-pool": "patches/pg-pool.patch" is added; "other@1.0.0" is untouched')
    then('the install exits 0; the cycle check exits 0')

given('[case2.own] an rds repo whose map holds only "pg-pool@3.14.0"')
  when('[t0] declapract apply, then pnpm install, then npm run test:lint:cycles')
    then('"pg-pool": "patches/pg-pool.patch" is added; "pg-pool@3.14.0" is untouched')
    then('pnpm applies the exact key first; the cycle check exits 0')
  when('[t1] pg-pool resolves to 3.14.1, then declapract apply')
    then('stale-patched-dependency drops "pg-pool@3.14.0" and its file; the shipped key remains')
    then('the cycle check exits 0')

given('[case2.own+other] an rds repo whose map holds "pg-pool@3.14.0" and "other@1.0.0"')
  when('[t0] declapract apply')
    then('"pg-pool": "patches/pg-pool.patch" is added; both repo keys are untouched')
  when('[t1] pnpm install, then npm run test:lint:cycles')
    then('the install exits 0; pnpm applies the exact key first')
    then('the cycle check exits 0')
  when('[t2] pg-pool resolves to 3.14.1, then declapract apply')
    then('stale-patched-dependency drops "pg-pool@3.14.0" and its file')
    then('"pg-pool": "patches/pg-pool.patch" and "other@1.0.0" remain')
    then('the cycle check exits 0')
```
