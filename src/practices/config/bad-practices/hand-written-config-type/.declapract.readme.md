a repo stamped before #588 holds a hand-written `src/utils/config/Config.ts`. `getConfig` now types off `config.schema.ts`, so the hand-written copy has no reader and can only drift from the live schema (it drifted to `access: 'test' | 'dev' | 'prod'` in one adopter).

the fix deletes `src/utils/config/Config.ts` and repoints each import of it (`./Config` inside `src/utils/config/`, or any `…/utils/config/Config`) to `config.schema`, which exports the schema-inferred `Config`.
