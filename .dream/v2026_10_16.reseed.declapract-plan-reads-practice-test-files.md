- kind = reseed
- owner = ehmpathy/declapract
- caught 2026-10-16, on route `.behavior/v2026_09_29.fix-absorb-recent-upgrade-reports`

## .the cue that fired

the 5.3 ergonomics review walked `lambda-service-with-rds` through the real cli
(`rhx declapract.walk`). the final `declapract plan` printed ~400 lines, of which ~150 are
`[NO_CHANGE]` rows for files that are this repo's own tests, not declarations:

```
  * [NO_CHANGE] __snapshots__/.declapract.integration.test.ts.snap
  * [NO_CHANGE] .test/assets/demo-repo-with-joi/package.json
  * [NO_CHANGE] .github/workflows/provision.yml.declapract.integration.test.ts
  * [NO_CHANGE] package.json.declapract.integration.test.ts
```

## .the gap, precisely

- `declapract compile` copies every file under a practice dir into `dist/`, and the evaluator reads
  each one under `bad-practices/<name>/` as a declared file of that bad practice
- so a bad practice's `.test/assets/<demo-repo>/…` fixtures, its `__snapshots__/`, and its
  `*.declapract.integration.test.ts` each become a path the adopter's plan checks and prints
- the rows are `NO_CHANGE` today (an absent file never matches a bad practice), so the cost is
  noise: an adopter must scan past them to find the few rows that ask them to act
- the fixture placement is this repo's paved shape (`rule.require.declapract-integration-tests`),
  so the cure belongs in the engine, not in a move of every fixture

## .the shape of the fix

in declapract, skip test-only paths at compile and at evaluate:

1. a default ignore set — any path segment `.test/` or `__snapshots__/`, and any basename that
   ends `.test.ts` / `.test.ts.snap` — applied in `compile` and in the practice reader
2. optionally, a `declapract.declare.yml` key (`ignore: [...]`) for a repo-specific set
3. a test: a practice with a `bad-practices/x/.test/assets/demo/package.json` fixture yields no
   plan row for `.test/assets/demo/package.json`

## .why it is not done in this round

it lives in another repo (S5: no work in other repos this round), and the rows cost noise, not a
wrong verdict.
