## .narrative

the wisher opens the pr on `beav/feat-ts7-migration-probe`. ci is green. the body leads with the answer in one line: types-check is N× faster in wall time under typescript 7.0.2. a table backs it. four rungs share one command and one tsconfig: 5.4.5, 6.0.3, 7.0.2, and 7.0.2 `--singleThreaded`. each rung shows median wall, cpu (user + sys), and peak rss over five cold runs. the single-thread row shows how much of the gain is the native port and how much is parallel checkers. cpu can exceed wall under ts7; the table says so, so nobody reads a cpu climb as a regression.

below the table, the break list. each row names the error code, the option or construct at fault, and the fix the practice now ships. every fix also compiles under 5.4.5, so an adopter halfway through the upgrade stays green. the pr diff moves the `typescript` floor in typescript-node only, migrates the node tsconfig, and adds one bad-practice that strips the removed options. this repo takes its own practices, so the diff also shows its own `typescript` at 7.0.2: the green ci badge is a ts7 typecheck, not a 5.4.5 one. expo is left alone, and the body says why. a pushback footnote closes the body.

the aha: the speedup is a number with its method beside it, not a press-release claim. the break list is short, and each row carries its own fix.
