# 1.vision: linguist-generated robocode collapses in prs

## the outcome world

### before

a pr on a lambda-service-with-rds repo adds one field. github renders 41 files open: the regen of every dao, the sql tables, five test files, two snapshots, and the 6-line domain change a human must judge. a route pr is worse: stone prompts, guards, review transcripts, caches. the reviewer scrolls through robocode to find the human surface.

### after

the same pr renders the domain change, the snapshots, and the hand-written code open. dao output, `*.test.ts`, and route robocode sit collapsed under github's "some generated files are not rendered by default". each collapsed file keeps its `+N −M` count and a "load diff" link, one click away. in a route, only the `*.yield.*` files and the `.radio/` records stay open.

### a day in the life

kai reviews three prs before lunch. on each, the files tab opens on what a human wrote or must vibecheck. kai reads the snapshot diff as the proof, and clicks a test open only when the snapshot raises a question. route prs open on the yields: what the clone concluded, then what it handed off.

### the aha

the snapshot is the proof; the test source is the how. the yield is the conclusion; the route is the trail. the reviewer reads proof and conclusion first, and opens the how and the trail on demand.

## the contract

the declared lines, by owner practice (F1). one shared util, `defineExpectedGitattributesContents`, emits the whole file for every declarer: managed sections first, in a fixed order, then repo-own lines last (F4).

```gitattributes
# (git) the two lock-file sections, unchanged from today (their two header lines elided here)
pnpm-lock.yaml -diff
package-lock.json -diff
pnpm-lock.yaml merge=theirs
package-lock.json merge=theirs

# (tests-any) collapse test source in pr diffs; snapshots stay open
*.test.ts linguist-generated
*.test.tsx linguist-generated

# (persist-with-rds) collapse dao-generator output in pr diffs
src/access/daos/**/.generated/** linguist-generated
provision/schema/**/.generated/** linguist-generated

# (persist-with-dynamodb) collapse dao-generator output in pr diffs
src/access/daos/**/.generated/** linguist-generated

# (rhachet) collapse route robocode in pr diffs; yields and radio stay open
.route/** linguist-generated
.route/**/*.yield.* -linguist-generated
.route/**/.radio/** -linguist-generated
.behavior/** linguist-generated
.behavior/**/*.yield.* -linguist-generated
.behavior/**/.radio/** -linguist-generated

# (repo-own lines, kept, always last)
```

each shipped header carries its declarer as a `# [practice] ` tag (F7); the `(practice)` labels above stand in for it. the daos and the schemas stay open: they are the internal contracts, so only the `.generated/` dirs within them fold (F3). a line two declarers share (`src/access/daos/**/.generated/**`) lands in each declarer's section: no fix edits another declarer's section, and both copies collapse, so the repeat is inert (F11).

three git facts make this shape load-bearing:

- **last match wins.** each exception follows its collapse line, and repo-own overrides follow every managed section
- **no negative patterns.** git ignores a `!pattern` line in `.gitattributes` (probed: `unspecified`); the un-collapse form is `pattern -linguist-generated`
- **attributes never recurse from a dir.** `.route/` matches no file; `.route/**` does

`*.snap` needs no line. linguist does not auto-mark jest snapshots, so they render open by default.

## mental model

- to a friend: "github folds the generated stuff and the tests, so the pr opens on what you actually need to read."
- analogy: a book's appendix. the content sits in the back, complete, one flip away; the chapter reads clean.
- their terms vs ours: they say "folded", "hidden", "collapsed"; we say `linguist-generated`. they say "the robot files"; we say robocode. a test file is not literally generated; the attribute is a render hint, and the shipped header comment says so ("collapse ... in pr diffs").

## evaluation

### goals

| done-means line | met by |
|---|---|
| practice ships the entries to an adopter | owner practices + shared util (F1); case=3 |
| dao output + `*.test.ts` collapsed; `*.snap` open | case=1 |
| `.route/` collapsed except `.yield` and `.radio` | case=2 (+ `.behavior/`, F2) |
| collapsed file one click away | github "load diff"; native, no work |
| pilot: two numbers on one pr | case=5 |

### pros

- the human surface opens first on every pr, with no reviewer setup
- zero loss: every file stays in the pr, counted, one click away
- a repo opts any path back out with one line that wins (case=4)
- side effect: language stats on the repo page exclude robocode (see cons for the code search risk)

### cons

- a test weakened to go green sits one click deeper (rv6, case=6)
- the git practice's file order inverts once per consumer (F4): a one-time diff
- the multi-declarer util is real work: convergence tests across five declarers (F1)
- **risk, unverified:** github code search states "vendored and generated code is excluded". if that exclusion honors `linguist-generated`, every `*.test.ts`, dao, and route file drops out of github code search (Q6)

### edgecases and the pit of success

| edge | how the contract keeps the user safe |
|---|---|
| two declarers fix in turn | one shared util emits the whole file; `fix_A ∘ fix_B == fix_B`; cross-declarer test (inv1) |
| repo override lost to order | repo-own lines always last; test asks `git check-attr`, not the line order (case=4) |
| a usecase lacks a declarer | each practice ships only its own section (dd2, dd3, dd4) |
| re-apply | `check(x) ⟺ x == fix(x)`; zero bytes on a second run (ad6, ad10) |
| a test file is weakened to go green | the collapsed row still shows `+N −M`; the snapshot diff stays open; `git diff` and ci see every line (case=6) |

### the external contract and its exception

the render on github is the external contract this practice ships. the suites prove what git computes for each path (`git check-attr`, `git diff --numstat`); no automated test calls github for the render. the exception, per `rule.require.external-contract-integration-tests`:

- **no api reports the fold.** the pr files endpoint returns `sha, filename, status, additions, deletions, changes, blob_url, raw_url, contents_url, patch, previous_filename`; none marks a generated file ([rest: list pull request files](https://docs.github.com/en/rest/pulls/pulls#list-pull-requests-files)). an automated check could only scrape the pr page's html, which carries no contract
- **a real call needs a sandbox repo and a ci write token**, which this repo does not hold; their creation is the foreman's call
- **the real call is the pilot pr.** a human reads one pr with the lines in place and records Q7–Q10 (`5.3.verification.handoff.v1.to_foreman.md`). git's computation is the local proxy; Q8 names the one place it may diverge (libgit2's matcher)

fork and confidence: F17.

## groundwork

### external research

- github docs, [customize how changed files appear](https://docs.github.com/en/repositories/working-with-files/managing-files/customizing-how-changed-files-appear-on-github): `linguist-generated` files are "hidden by default in diffs"; un-mark via `-linguist-generated`
- linguist, [overrides.md](https://github.com/github-linguist/linguist/blob/main/docs/overrides.md): generated files "are suppressed in diffs"; negation by `-` prefix
- linguist, [`generated.rb`](https://github.com/github-linguist/linguist/blob/main/lib/linguist/generated.rb): no `.snap` detection; the only `.ts` detection is protobuf output. so every collapse here must be declared, and `*.snap` needs no line to stay open
- git `gitattributes(5)`: last match wins; negative patterns forbidden; a dir pattern does not recurse. proven locally with `rhx git.attr.get` (paved this stone) against a scratch `.temp/linguist-probe/.gitattributes`:
  - `*.test.ts` → `set` for `foo.test.ts` and `foo.integration.test.ts`; `unspecified` for `foo.test.ts.snap`
  - `.route/**` then `.route/**/*.yield.*` / `.route/**/.radio/**` with `-linguist-generated` → stone `set`, yield `unset`, radio `unset`, nested `.route/cache.json` `set`
  - `src/access/daos/**` then `src/access/daos/custom/** -linguist-generated` → `daoJob/upsert.ts` `set`, `custom/findJobs.ts` `unset`
  - `.dironly/ linguist-generated` → `.dironly/a.ts` `unspecified` (no recursion)
  - `!negated.ts linguist-generated` → `unspecified` (negation ignored)
- not yet verified: the exact github ui strings ("some generated files are not rendered by default", "load diff") are recalled, not fetched. the pilot confirms them on a live pr

## what is awkward?

- **a test is not generated.** `linguist-generated` names a render hint with a provenance word. the header comment carries the true intent; the attribute name does not
- **one file, five declarers.** `.gitattributes` grows the same multi-declarer machine `.gitignore` has. real cost for a handful of lines, but the alternative breaks the owner rule
- **the reorder.** every consumer's lock-file block moves above its own lines once. harmless, but a diff nobody asked for
- **a weakened test sits one click deeper.** linguist cannot open a file on a condition (say, "lines deleted"), so the `+N −M` counts on a collapsed row are the only tell. a reviewer who ignores collapsed rows can miss it (case=6)
- **the pilot measures a human.** the clone computes a proxy; the minutes need a stopwatch and a person, and a same-diff re-review flatters the after number
