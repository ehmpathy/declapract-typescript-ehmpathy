`@tsconfig/node-lts-strictest` left in package.json after the tsconfig swap.

the typescript-node tsconfig extends `@tsconfig/strictest` + `@tsconfig/node20`. once no root
`tsconfig*.json` extends `@tsconfig/node-lts-strictest`, the fix removes it, so depcheck stops
flags on it. while a tsconfig still extends it, the package stays, so tsc can still load the config.
