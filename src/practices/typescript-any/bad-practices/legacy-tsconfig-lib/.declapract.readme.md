a tsconfig `lib` override with no es2022-capable entry (e.g. a legacy `lib: ["DOM"]`).

a `lib` override replaces the `@tsconfig/node20` default, so it drops the ES2022 `ErrorOptions`
type, and the shipped `new Error(msg, { cause })` templates fail `test:types` with TS2554.

the fix appends `"ES2023"` to the array and keeps each extant entry and comment. to drop the
override entirely is also correct, when the repo needs none of its entries.
